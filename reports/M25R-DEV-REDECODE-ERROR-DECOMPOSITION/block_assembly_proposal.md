# 下一范围提案：冻结状态上的跨block CDS组装可达性

2026-09-08；PROPOSED，未实施、未提交作业。不是重新训练申请。

## 为什么不再做一次普通可达性统计

已检查既有reference_case_correction.tsv：epoch1/2/3各6450参考，全链transition-reachable分别3727/3993/4017，motif-reachable分别3616/3852/3862。既有transition_upper_bounds检查的是各真边界能否分别出现在全染色体transition附近±6 bp的合法motif集合，不要求它们属于同一block。因此“跨block能否找到所有真边界”的宽松上界已经存在，不应为同一问题重复计算。

但各个边界分别存在，不等于它们能组装为合法完整CDS链，更不等于无参考辅助时可以选中该链。新问题必须进一步要求候选CDS片段及链连接兼容。

## 单次CPU诊断的新增问题

固定epoch1/row601的region state与原±6 bp motif搜索空间，在允许跨block连接、但不创造新的motif坐标的前提下，参考完整CDS链是否存在于候选结构空间？这是取消“整条基因必须属于一个non-intergenic block”限制的机制可行性诊断；它不同于已经完成的phase-only实验，需要新的范围授权。

拟执行边界：

- 仅拟南芥NC_003074.8、水稻NC_089041.1，6450条冻结complete-primary参考；只用现有epoch1 lineage/state、原FASTA和参考GFF。
- 按原state transitions和±6 bp motif规则，记录候选CDS左右端点的事件类型及顺序。允许跨block连接，但不改变原region阈值、motif半径或候选坐标。
- 检查完整真CDS链每个片段的端点兼容性、正长度和链顺序；区分“单边界存在但片段不可组装”“候选片段存在但整链不兼容”“全链存在”。对phase和分数过滤暂作最乐观放宽，因此只能给结构空间上界。
- 参考仅用于查询真实链是否存在，不用于产生实际预测或选择模型；不得输出reference-assisted GFF充当无参考注释结果。无须枚举所有可能的整基因路径。
- 分别报告全量与既有1634条跨block碎裂类别；另列gene-span、跨越block数、被跳过候选片段数，说明后续无参考解码需面对的组装歧义，不从参考分布选择距离阈值。
- 用既有精确输出检查坐标和端点可达性；若既有精确输出被新检查判为不可达，停止并报告诊断实现不一致，不用该失败否决科学机制。

## 预算与停止条件

建议一次CPU Slurm：private-teodoro-gpu，2 CPU，16 GiB，30分钟硬上限，generanno既有环境；0 GPU、0训练、0新前向。产物独立存放，原数据、checkpoint、冻结结果和阈值不改。失败或超时停止，不自动修复重投；不创建后台监控。

结果若连最乐观候选结构空间都不足以达到冻结必要指标，则关闭“仅重新组装现有候选”的方向。若上界允许，不视作GO：交付一个明确的无参考组装机制及其所需分数/资源方案，另行请求授权，不自动进入GPU或训练。

上界必须按实际集合计数推导，不能把可达参考数除以6450直接叫F1；不能沿用phase-only的709个固定FP常数，因为新的组装器可能改变原输出。不能把参考辅助检查所得优势当作模型性能。Setaria继续封存，所有原success gates保持不变。

## 当前决策

phase-only已由全量上界排除；候选空间重组尚未被排除。当前证据不足以正式关闭整个GENERanno路线，也不支持启动新head训练。以上单次CPU诊断用于决定是否值得申请真正的无参考跨block组装实验，而非开启无限调参。
