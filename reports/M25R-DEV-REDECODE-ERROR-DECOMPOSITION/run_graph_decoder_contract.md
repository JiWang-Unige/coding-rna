# M25R-E1-RUN-GRAPH-R1：无参考组装算法合同

日期：2026-09-08。版本R1；算法与评分提案固定，执行尚待批准。本文不授权提交作业、训练或Setaria访问。

## 唯一研究问题

固定epoch-1权重和row601候选生成参数，使用原run支持的候选CDS图与序列合法性，替代“每个block输出整条基因+phase硬拒绝”，是否改善完整开发集且达到原必要门槛？这是一个联合解码机制，不可将其效果单独归因为跨block或phase；已有phase-only上界作为独立负结果保留。

仅拟南芥NC_003074.8、水稻NC_089041.1。参考GFF只允许在独立评价步骤读取；图生成、打分、选路及预测导出不接收参考路径、真链ID、oracle结果、物种特定参数。两物种、双链同规则。

## 1. 候选图：不扩大已诊断的坐标空间

使用原6144 bp整染色体正向/反向互补切窗、同tokenizer与bf16→float32→float16保存规则。region阈值0.4、事件类型TRANSITIONS、半径6 bp不变。

每个原CDS run的两端分别枚举合法start/acceptor与donor/stop motif，组合为正长度CDS候选；首CDS以start开始，末CDS以stop结束，内部端点为acceptor/donor。每个CDS必须由同一原run支持，不把两个run拼成一个CDS，不在run内部另建切点。

保留原边界硬阈值start=stop=0.5、donor=acceptor=0.1；低于阈值的候选端点不进入图。连接只沿同一染色体同一方向的递增run，donor后至少4 bp才到下游CDS起点。允许跨block和跳过run，不设置最大内含子长度、距离档位或参考驱动的连接窗口。

phase头不作拒绝，也不作打分。完整ORF仍须ATG起始、合法终止密码子、长度至少6且为3倍数、无内部终止；最终phase由累计CDS长度计算。连接时跟踪未完成密码子的0–2个碱基（1+4+16种状态），保证跨exon密码子也检查，而不只逐exon检查。

## 2. 固定评分公式

记每位置原region logits为z_I,z_C,z_G。以整条染色体保持intergenic为零基线。对一条合法基因路径P：

S(P) = sum_CDS(z_C-z_I) + sum_introns(z_G-z_I)
       + sum_selected_boundary_events(logit_event - logit(frozen_threshold_event)).

CDS使用半开区间；intron为前CDS结束至后CDS开始，不重复计数端点。一个实际start/stop/donor/acceptor事件只计一次。上述区域差等价于softmax概率比的对数，直接用float64累加float16保存的logits，避免人为epsilon和概率裁剪。所有权重固定为1，不拟合或扫描。

这是预先规定的未校准能量函数，不声称为独立概率模型或真实基因后验。每碱基证据与边界证据的相对尺度可能导致失败；失败后不能以“校准”为由在本次验证集继续调权。

## 3. 多基因选择、防融合与输出

每条染色体每个方向，全局选择一组基因组跨度不重叠的完整ORF路径，使总S最大；未选择区间保持intergenic、得分0。不同方向独立，可相互重叠。同链不输出重叠isoform或嵌套基因，这是明确的模型限制，而非评价豁免。

防融合由两个固定机制提供：跨越原强intergenic区域需支付sum(z_G-z_I)代价；一条融合路径必须与同区间多个独立完整基因的总得分竞争，而不是每个start独立贪心输出。二者不能保证不发生融合，必须在最终评价中报告split/fusion。不得另加从参考推导的最大跨度、基因数目标或奖励项。

仅输出严格提高总目标的路径；零增益选择不输出。目标值完全相同时先取较小总基因跨度，再取按原始基因组坐标排序的完整CDS链列表中字典序较小者；不使用真参考或物种身份破同分。输出一套确定性的GFF3，不保留Top-K候选供人工选最优。

实现采用有序图动态规划，不枚举所有完整路径。intron区间分数可由前缀和拆分为acceptor项和donor项；按合法密码子状态维护满足间隔约束的最佳前驱，从而避免全染色体所有donor×acceptor显式边。独立基因结束后回到intergenic状态，允许多个基因参与同一目标竞争。

## 4. 验证与一次运行顺序

第一步只做实现与合成验证：小图穷举对比动态规划；覆盖跨exon stop、负链映射、多个独立基因优于融合、真正长intron、全负分不输出、阈值等号、确定性同分及跨block/跳run。不得读取真实开发指标进行算法选择。算法验证失败则停止，交付具体问题；不自动修复重投。

第二步一次全开发集epoch-1前向，保存共享logits。A用原冻结解码器重放；必须复现R4原坐标指标（原协议1e-5容差）与完整输出链集合，再用大小写已纠正的独立结构审计，而不是重现旧错误validity。A不一致时停止，不计算或解释B。

第三步使用同一份logits执行B；无额外前向。预测完整落盘之后，独立进程才读取冻结参考评价。输出全部主指标、每物种结果、基因数/FPR、完整结构有效性、split/fusion、A→B链增删。可附全注释/partial解释，不替代complete-primary主指标。

此A/B不是原full-versus-ablation比较，不能用B-A冒充原ablation gain。即使B达到单模型门槛，仍需原要求的ablation及其余科学条件，不能直接进入Setaria或宣布GO。
