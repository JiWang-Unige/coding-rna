# M26 R3：严格实际图支持分解

2026-09-26，Pro 首轮代码审阅后、执行前固定。不是新预测或 decoder 改版；只读同两条开发染色体、同缓存、同参考和保存输出。Pro 建议的对象级分解由本项目独立实现和验证。

O0 是旧宽松 oracle（3,585）；O1 是通过原 R1 实际边界阈值、motif、同 run fragment、递增 run、至少 4 bp intron、完整 ORF 后的逐链可达集合；TB 是 B 的 3,351 条精确链。

直接调用未改的 `run_graph_core.candidates` 构建原实际候选，按真实 CDS 坐标及端点类型查找**全部** carrier run，判断是否存在任意递增 witness；不是只检查旧保存的一个 witness。负链转换到原始推理方向，ORF 使用未改的 R1 automaton 检查。phase 不在主链身份键内。不调用 `solve`，不改评分，不导出新预测。

固定四类：R−O0；O0−O1；O1−TB；TB。必须对账 R=6,450、O0=3,585、TB=3,351、TA=1,389，且 TB⊆O1⊆O0；失败停止归因。另列 A/B 精确真链转移与旧类别分层。以每链跨度、染色体和方向计算 O1 中最大同链不重叠参考子集，作为联合容量的额外上界，不称其为给定能量函数可实现的输出成绩。

统计三套既有基线分别恢复四类参考的条数。基线恢复 R−O0，表示当前 M25R 图限制不是所有工具共同不可恢复；不证明这些结构信号存在于 GENERanno logits，也不赋予基线内部候选 oracle。

一次 CPU Slurm，private-teodoro-gpu，0 GPU、4 CPU、16 GiB、40 分钟上限，预计数分钟；独立输出 `outputs/M26-ACTUAL-GRAPH-SUPPORT-R3`。三个合成测试分别验证任意 witness、实际边界/ORF、同链冲突上界。无新训练、前向、阈值扫描、Setaria 或其他封存数据访问。

决定：若绝大多数剩余漏检在 R−O0，停止把选路作为主要召回方向；若大量在 O0−O1，定位为过滤限制而非评分；若主要是 O1−TB，才保留选择机制问题。任何结果不推翻旧 NO-GO，也不自动构成普遍的新发现。
