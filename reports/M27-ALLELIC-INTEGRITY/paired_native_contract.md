## 输入与原生流程

固定GRCh38 chr22、GENCODE49、全部uppercase且无外部证据。每份完整50,818,468bp输入均直接从同一WT独立生成；全序列比较断言仅登记坐标发生指定单碱基替换，正负链密码子必须等于原登记synonymous Tyr或TAA。不裁剪、不多位点合并、不串接上一份mutant。

工具版本、权重、原生精度、窗口、batch和过滤与 [WT合同](wt_replay_contract.md) 一致。ANNEVO仍为原发布prediction.py→decoding.py两步；Tiberius仍为原生自适应控制器及真正神经前向。不得把WT的4次请求固定为mutant请求数，也不得以WT缓存代替改变后的请求。wt_tiberius.py仅增加native轨迹模式：原样返回原生前向结果、不保存整数组缓存，记录真实请求与两次过滤前后链。

保留WT全部缓存及每例完整命令、原始GFF/GTF、日志、运行状态、变异清单，Tiberius另存请求和过滤轨迹。ANNEVO每例HDF5是临时产物，仅在完整解码、无吞掉的worker错误、GFF解析与响应记录计算成功后删除；所有病例同一政策，不因阳性而选择性保留。失败时尚存的临时文件保留。未来机制确认若需神经分数，必须重新计算其指定DNA的完整原生请求，不能事后声称本轮已分离各分量。

## 固定身份与严格bypass终点

以唯一精确WT链为参考，按转录方向定义首/末完整CDS块（含起止端点），并固定整个编辑密码子的三个基因组坐标。锚匹配必须包含seqid、strand、坐标与phase；不依赖生成ID或最近邻，不拼合多条预测的并集。

明确BYPASS必须同时满足：

- 唯一单条最终预测仍以这两个原CDS块分别作为首、末块，且没有其他预测竞争任一个完整锚块；
- 剪接连接改变，整个编辑密码子的三个碱基落在该单链的一个内含子中；
- 在实际mutant DNA上，CDS phase连续、以ATG起始、标准stop终止、长度为3倍数、无内部stop或模糊碱基；
- 新增CDS没有接入同strand其他已注释gene的、目标gene所有CDS/stop isoform并集之外的编码区域。该定义是相对目标gene的独有区域，不要求它在所有其他gene之间也唯一。仅作FUSION_SUSPECT保守标签，不宣称生物学融合。

这些规则用于响应判定，不重新筛W_m。GENCODE全部CDS/stop记录仅用于这个保守的外来编码标记，不能借此重新计算WT分母或把参考外结构一律当假阳性。

## 分类与保守边界

| 类别 | 明确规则 | bypass区间 |
|---|---|---|
| BYPASS | 满足上述所有条件 | [1,1] |
| PTC_TERMINATION | 唯一相关输出为WT从起始至登记PTC的精确CDS前缀，确实在该PTC结束且ORF有效 | [0,0] |
| DOWNSTREAM_RESTART | 唯一相关输出从该密码子之后的ATG开始，为WT精确CDS后缀、保留原stop及合法phase；该完整链不在原WT预测中 | [0,0] |
| OUTPUT_SPLIT | 恰有两条相关输出，分别为可对应的WT上游前缀及上述新起始后缀，无单链连接；前缀必须保留至少完整5′锚并结束于编辑密码子末端或之前 | [0,0] |
| WT_CHAIN_RETAINED | 唯一无竞争双端锚链与WT完全相同；出现内部stop也照实记录 | [0,0] |
| OTHER_IDENTIFIED_STRUCTURE | 唯一无竞争双端锚、无外来编码混杂，但不满足严格bypass | [0,0] |
| OUTPUT_ABSENT | 运行完整，完全没有同strand CDS-span与WT CDS-span相交的最终输出 | [0,0] |
| 歧义/不可归属/融合疑似/技术性未完成 | 多候选、竞争锚、readthrough延伸、只剩不足锚，或仍有相交输出却不满足前述明确规则 | [0,1] |

“相关”在这里取同strand且CDS-span与WT CDS-span相交的保守集合。因此只有一个明确前缀/后缀但同时还有其他相交输出时也记不可归属，不放宽为最近邻。不能把“无双锚”直接记成消失。原先已存在的邻近WT链不能充当新restart。

过滤删除另作过程标签：必须在具体过滤前有唯一可对应链、该键在过滤后确实不存在，分别记录min-coding和internal-stop。只在最终确实OUTPUT_ABSENT时才能讨论该观察与最终消失一致；ANNEVO没有这类轨迹，不猜删除原因。过滤前bypass最终被删除，不算最终阳性。

## 固定分母、结果与停止

每条件记录[L,U]，每工具固定n=12或10：
差值识别界限 = [sum(L_PTC-U_syn)/n, sum(U_PTC-L_syn)/n]。
它不是置信区间。完整配对的00/01/10/11四格和未知配对都列出，不能只报完整病例子集比例。共同9用同一规则另报。正反变化抵消不写成“无响应”。

如果没有明确PTC=1/syn=0配对，或只有不能归属的变化，结束本固定先导并报告，不放宽锚、不增位点、不改终点。全部配对明确且两条件均无bypass时，只能说该条件面板内未观察到这一严格响应。

如果有明确PTC特异配对，下一阶段每工具最多选登记坐标最前的一个；先完整重算原生syn/PTC确认重现，再另定分量交叉。没有任意“至少5例”门槛。工具层方向性需保守差值下界>0；仅一个工具支持就限制该工具，两工具均支持才讨论跨工具扩展。界限跨0时具体个案仍可确认，但不能升级成总体倾向。未测真实生物学证据、未知训练暴露及ACE/SGRF先行工作继续限制新颖性主张。
