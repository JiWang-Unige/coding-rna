# Complete gene grammar model figure caption

The base model separates neural scoring, observation likelihood and raw FASTA decoding. **a**, An annotation-pretrained GENERanno encoder remains frozen while the C0 head combines aligned six-mer features with a trainable DNA convolution branch to emit fifteen role scores per base. Complete-set energy sums role-minus-background scores with unit weights. **b**, Training uses finite DNA views containing an observed core and its stride neighbors. Exact fine labels, a fixed three-class coarse-only observation channel and marginalized unknown positions define the observed partition. Both the unrestricted and observed partitions sum over all permitted complete gene sets; observations enter only the latter. The normalized, importance-weighted loss updates the head but not the encoder. Finite-view likelihoods are not chromosome-joint maximum likelihood. **c**, Inference uses only FASTA and the fixed final checkpoint. A nearest-containing-center ownership rule stitches neural-window scores into a single row per oriented contig base. Complete-set MAP decoding then operates over the whole contig, so genes can cross neural-window boundaries. Output consists of complete CDS chains with GFF3 coordinates and phases, not UTRs or all alternative isoforms.

The same explicit DNA grammar governs both message passes: ATG initiation; TAA, TAG or TGA termination without internal in-frame stops; actual coding-base carry across introns; GT or GC donors and AG acceptors; at least five intronic bases; at most 128 exons per gene; and nonoverlapping gene spans within a strand. Opposite-strand overlaps and the empty gene set are allowed. Decoder exactness refers to this structural universe, not every biological gene. Freezing an annotation-pretrained encoder does not establish exposure-free generalization. This schematic describes the implemented base model, not the separate native-head-prior or joint-context experiment branches, and does not encode an accuracy or novelty claim.
