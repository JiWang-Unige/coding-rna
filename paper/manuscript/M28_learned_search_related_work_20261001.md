# M28 基因结构搜索的相关工作与贡献边界

2026-10-01。本记录补充当前新方法路线中尚未系统列出的学习型搜索先例，供研究决策和后续论文写作使用。结论是：在剪枝前学习非局部评分、用正确前缀退出搜索的事件训练、用候选图表示基因，都已有明确先例；B2不能仅凭这些组件宣称首创。仍待检验的任务特定价值，是在固定候选资源下改善自由完整CDS链恢复，并把收益保留到染色体最终输出。

本文不修改[B2首训合同](../reports/M28-METHOD-RESTART/b2_first_fit_contract.md)，不报告新的DEV成绩，不授权追加训练、改变候选预算、释放封存数据或投稿。正式实现的固定版本及三阶段作业另见[B2执行记录](../reports/M28-METHOD-RESTART/b2_execution.md)。

## 文献事实及其与当前方法的关系

本轮用Exa作五个定向检索，共28个返回结果额度，覆盖学习型搜索与基因结构图两个主题。重复网页和二手聚合页不作为方法证据；这不是28篇全文精读，也不是穷尽性新颖性检索。下表事实来自原论文方法段，DAGGER仅使用作者摘要，GeneDecoder使用2025年预印本的模型及评价段。表中的“当前差异”是基于项目合同的比较推断，不是原文对本项目的评价。

| 原始工作 | 原文已存在的机制 | 当前差异或不能借用的结论 |
|---|---|---|
| Collins与Roark，2004，[Incremental Parsing with the Perceptron Algorithm](https://aclanthology.org/P04-1015/) | 第4.2节在正确部分解析退出beam时终止该例搜索，并立即以部分结构更新参数；第4.1节还复用已生成候选进行参数更新。 | 首截断监督和候选缓存不是新概念。B2的训练事件来自冻结加性控制搜索，不随新头更新重新生成，且仍另有完整链BCE；不能称原版early update的复现。 |
| Daumé III与Marcu，2005，[Learning as Search Optimization](https://icml.cc/Conferences/2005/proceedings/papers/022_LearningAsSearch_DaumeMarcu.pdf) | 第3.2至3.3节学习搜索队列排序；没有正确可续接状态时更新参数，并把队列恢复为正确状态继续搜索。 | LaSO的搜索与学习耦合、恢复正确路径都已有先例。B2不做这种重置或在线控制策略更新，因此不能借用其收敛定理或称已解决搜索分布失配。 |
| Wiseman与Rush，2016，[Sequence to Sequence Learning as Beam Search Optimization](https://aclanthology.org/D16-1137/) | 第4节以RNN产生非概率序列分，针对正确前缀与beam边界的间隔违例训练；搜索可施加硬语法约束，违例后从正确历史继续。 | 神经前缀评分、beam感知损失和受约束搜索本身都不是新贡献。B2用softplus配对加完整链BCE、固定控制首截断事件和基因事件图，并不等于BSO算法。 |
| Chuang与Roth，2001，[Gene recognition based on DAG shortest paths](https://pubmed.ncbi.nlm.nih.gov/11472993/) | 作者摘要描述DAGGER用学习的start/donor/acceptor/stop传感器建DAG，优化边权，再取表示基因结构的最短路径。 | 候选端点图和判别式基因路径学习已有先例。摘要不足以判断其所有实现细节；不能据此断言已有或没有与B2完全相同的非加性前缀机制。 |
| Marin等，2025，[Gene finding revisited](https://arxiv.org/abs/2505.03377) | 第3.1节用学习的DNA表示接latent CRF，潜状态表达方向和codon结构，Viterbi作精确解码；评价包含碱基标签MCC与macro F1。 | 学习表示加结构约束不新。其有限状态CRF的精确解码不同于B2历史依赖的近似搜索；原文标签分数不能当完整CDS链分数与本项目排名。此处是预印本来源，不将网页上传时间当作期刊发表时间。 |

这些来源否定的是宽泛“组件首创”说法，并没有直接检验本项目的基因事件表示、监督政策或完整方法，也不能据此预先判定B2必然有效或无效。现代基线与更早结构化基因训练的来源仍保留在[研发计划](M28_method_development_plan_20260929.md)；本轮不拿原论文不同数据、任务和分母的成绩拼接SOTA表。

## 当前真正被检验的机制

[R6固定追踪](../reports/M28-METHOD-RESTART/r6_trace_result.md)在两物种选定样例中发现：满足整链ORF语法、保留必要端点和连接、参考carry下exon边可行的路径，仍可能在实际加性beam或最终上限首次被裁掉。它支持测试评分位置，但样例不是随机总体，不能推断全DEV的剪枝归因比例；被丢失之后的条件化可行性也不是实际执行轨迹。

B2以同一个新拟合前缀头比较early与late，冻结基座、端点/连接来源、语法、预算、owner及selector；共同候选使用单次union最终读出，late逐窗重放原池。因此，若完整对照成立，它回答的是“在这套系统中评分位置是否改变候选与完整输出”，而不是“某种新训练架构是否胜过所有方法”。B2继承基座4608次更新，再增加新头4608次更新；它与历史C0/B1没有自动成为总训练曝光匹配的方案对照。

更准确的当前描述是“在冻结控制搜索的首个实际截断事件上监督的绝对前缀兼容性”。它不是自然候选正确概率、具有最优性保证的值函数、A*可采纳启发式，也不是可微的离散搜索。GRU的历史依赖允许非加性评分，却不保证精确全局最优。

可能形成任务特定贡献的组合，是有向exon及真实跨剪接codon carry、空起点与已延续前缀的竞争、未知或其他isoform保护、训练参考注入与自由推理分离，以及搜索收益经owner和选择后仍成为正确完整CDS链。这里的“可能”是设计假设；这些细节分别出现或组合实现，不足以独立证明新颖性、跨物种收益或期刊档次。

## B2终态将决定什么

沿用事前合同，不添加新的通过门槛。完整4608步、8690个DEV方向窗、控制重放和共同gain核对先成立，才解释性能；不完整或重放不匹配的对照不排名。early必须在两物种分别提高自由完整链数、owner完整链数及最终exact-chain F1，且两物种背景span覆盖均不增加，才满足本轮机制继续条件。

若满足条件，下一判断是收益是否具有足够的最终输出幅度、相对历史C0/B1和同口径工具处于什么位置、以及实际推理代价。通过位置机制条件不自动证明完整方法领先，也不自动启动独立物种实验。

若只改善自由池而没有改善owner或最终F1，不能把搜索覆盖写成注释质量。若单物种改善或背景负担增加，原条件仍不通过。若条件不通过，关闭当前版本的成功主张，但不把固定off-policy训练、既有端点瓶颈或可能未充分拟合的问题概括为所有学习型搜索不可能有效；新假设须另定协议，不能事后改K、seed、步数或阈值。

## 达到论文主张还缺少的证据

以下是完整目标尚需解决的工作，不是本轮新提交计划：

- 完整方法收益需在同一输入、参考定义和评价器下，对当前适用版本的ANNEVO、Tiberius、Helixer比较；现有缓存结果只证明所记录历史输出的同口径成绩。任何训练方案因果比较还需匹配额外训练曝光，不能把B2新增学习量忽略。
- 两种植物DEV均已用于方法开发。独立迁移需在查看其性能前固定对象、权重、操作点及数据暴露政策；染色体隔离不等于同源隔离，监督未见不等于基础模型预训练未见。Setaria继续封存，不因本次文献结论放行。
- 当前输出是primary protein-coding CDS链，不是全部UTR或所有isoform；长链和不支持结构仍在分母中。更广适用范围需要实际独立证据，不能由窗口几何覆盖或结构合法性推断。
- 背景span/CDS覆盖与链每Mb是参考相对负担，不是生物学真负例率。独立转录或蛋白证据如用于裁决，应与DNA-only推理输入分开，且另定使用范围。
- 机制证据、完整基因效益、运行资源和迁移稳健性需要共同成立。一次位置对照通过只使该路线值得继续，不等于Nature Communications贡献成立或录用承诺。
