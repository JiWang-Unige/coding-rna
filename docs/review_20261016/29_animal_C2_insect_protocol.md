## 1. 昆虫的参考注释完善吗？会不会影响结果？

### 1.1 三类注释来源（事实）

**黑腹果蝇：FlyBase 人工精修。**
- NCBI RefSeq 的果蝇注释直接导入 FlyBase：`GCF_000001215.4`，注释名 "FlyBase Release 6.54"，2023-12-26 导入。蛋白编码基因 13,962 个，基因总数 17,872 个。
- FlyBase 由专职人员结合文献和转录组证据逐个修订基因模型，是昆虫里最好的参考注释。
- 但它也不是"完整真相"。据我所知（本任务未逐条核实）：每个版本仍在修改一部分基因模型；很短的开放阅读框和部分 lncRNA 是否编码蛋白仍有争议；少数基因有终止密码子通读或非 AUG 起始。最后这类在我们的序列检查里会被判为不可作正例，训练时标为未知。
- 果蝇在本设计里只作老物种（全标签训练加检查点选择），不进入 P4 的评估集合。

**NCBI RefSeq（EGAP / Gnomon，有 RNA-seq 证据）。**
- 覆盖面：截至 11-04，NCBI 上染色体级、带 RefSeq 注释的昆虫参考基因组共 211 个。其中双翅目 77、膜翅目 52、鳞翅目 41、鞘翅目 15、半翅目 10、直翅目 7，其余各目 1–2 个。210 个由 NCBI EGAP 注释，1 个（果蝇）来自 FlyBase。
- 方法：EGAP 用 Gnomon 合成基因模型，证据来自 RNA-seq 比对、同物种转录本和近缘物种蛋白，证据不足的区段用 ab initio 补齐。除少数模式种外，几乎全部是 "model RefSeq"（XM_ 号）预测，不是人工审定的 NM_。
- 注释报告给出几项可直接衡量证据的指标：
  - **fully-supported**：外显子和内含子全部有转录本或蛋白比对支持的 mRNA 比例；
  - **> 5% ab initio**：超过 5% 的长度来自 ab initio 预测、没有证据支持的 mRNA 比例；
  - RNA-seq 比对的 reads 总数；
  - BUSCO 完整度（蛋白模式，每个基因取最长蛋白）。
- 质量差异（121 个满足"≤ 700 Mb、2022 年后注释、BUSCO ≥ 97%"的基因组逐个读了报告，见 §2.3）：
  - BUSCO 几乎全在 97–99.8%，区分度很小。原因是 BUSCO 只看保守的单拷贝直系同源基因。NCBI 多数用目级谱系（diptera_odb10 3,285 个、lepidoptera_odb10 5,286 个、hymenoptera_odb10 5,991 个），少数用 endopterygota_odb10（2,124 个）或 insecta_odb10（1,367 个）。
  - 证据指标差别大得多。fully-supported 从 85% 到 99%，"> 5% ab initio" 从 0.3% 到 12.5%。
  - **最弱的是蚜虫**：豌豆蚜 86.4% / 11.4%，Metopolophium dirhodum 85.1% / 12.5%，棉蚜 90.1% / 8.1%。它们的 BUSCO 却有 98.6–99.6%。BUSCO 高不代表非保守基因注释得好。
  - 另一类问题是基因很长。烟粉虱的基因长度中位 11.9 kb，远超我们 24,576 bp 的训练窗口。
  - 注释版本也有新旧之分。西方蜜蜂（Vipsania 的昆虫测试种之一）的 RefSeq 注释还是 2018 年的 Release 104（EGAP 8.1）。
- RNA-seq 量：多数在 10 亿到 100 亿 reads 之间，少数只有几千万到几亿，例如 Arctopsyche grandis 0.24 亿、Diorhabda carinulata 5.7 亿。

**提交者自带注释（GenBank，GCA）。**
- 方法各异（BRAKER、MAKER、Helixer 等），证据来源和版本不统一。很多只有组装、没有注释；不少 Darwin Tree of Life 的鳞翅目基因组只有 Ensembl 的注释，没有 RefSeq 注释。
- 这类注释会让物种之间的"参考口径"不一致。方案 19 §1.1 在植物上已经排除它们，这里同样排除。

### 1.2 参考注释不完整对本检验的方向性影响

记参考漏掉的真基因比例为 m，参考里本不存在的错误基因模型比例为 s。

1. **训练侧：对两臂是共同噪声。**
   - U 臂只把参考中已注释、但这次没被抽中的那 50% 基因位点标为未知。参考漏掉的真基因，在 U、F 两臂里都被当作背景。
   - 两臂的"真基因被当背景"比例：U 为 m，F 为 m + (1 − m)/2。两臂之差是 (1 − m)/2，m = 0.1 时为 0.45，m = 0 时为 0.5。处理对比几乎不受 m 稀释。
   - 可能的削弱：如果两臂本来就被大量假背景压低了报出率，F 多出来的那部分假背景边际伤害可能变小。这一点只是推测，没有数据。
2. **评估侧：对 U 臂不利，检验偏保守。**
   - 评估时，模型报出的、参考里没有的真基因都算假阳性。U 臂报出更多基因：植物上 k50U 预测 6,064 条，k50F 预测 5,377 条，参考 5,793 条。所以 U 臂被多扣的精确率更多。
   - 用植物 P4 的汇总数字做一个简单推算：把植物参考当作完整真相，再假设藏掉其中比例 m 的基因；两臂的预测不变，命中被藏基因的预测改记为假阳性。

     | m | 被藏基因与已注释基因同样容易命中 | 被藏基因的命中率只有一半（漏注的多是难基因） |
     |---|---|---|
     | 0 | +3.24 | +3.24 |
     | 0.05 | +3.06 | +3.14 |
     | 0.10 | +2.87 | +3.03 |
     | 0.20 | +2.49 | +2.80 |
     | 0.30 | +2.09 | +2.54 |
     | 0.40 | +1.68 | +2.25 |

     表中是观测到的 k50U − k50F。也就是说，参考越不完整，观测差值越被低估。植物量级的真实差值，在参考漏掉约 30% 以上真基因时才会跌到 +2.0 附近。
3. **参考里的错误基因模型（s）：方向不定，用入选标准压低。**
   - 训练侧：对错误模型，F 臂"填背景"反而是对的，U 臂"标未知"是中性的，略偏向 F。
   - 评估侧：错误模型如果长得像基因（例如转座子来源的 ORF），报出更多的 U 臂更容易"命中"，略偏向 U。
   - 用 "> 5% ab initio ≤ 4%" 和 "fully-supported ≥ 94%" 两条标准把 s 压低（§2）。
4. **基因结构错误（外显子边界错）：共同噪声。** exact-chain 口径下两臂都会因此丢分，差值略被压缩。
5. **统计噪声：每个区段的评估基因较少。**
   - 按蛋白编码基因数 / 主染色体长度粗估，候选新物种约 30–70 个基因/Mb，8 Mb 区段约 230–570 条参考。植物的 8 Mb 区段取自染色体端部，基因较密，为 565–955 条。
   - 单物种差值的抽样误差因此更大，"≥ 3/4 同向"这一条更容易因噪声不成立。
   - 对策：验证区段按基因数延长（§3.2）。

**植物上的旁证（仅一例，不能归因）**：注释证据最弱的几内亚薯蓣（BUSCO 92.4%，RNA-seq 11.6 亿 reads，非标准剪接 10.8%）的差值最小，只有 +0.20；其余 7 个新物种为 +1.50 到 +8.31。这与"噪声压缩差值"的方向一致，但只有一个物种，也可能有别的原因。

**什么情况下噪声会淹没差异**：
- (a) 参考漏注 ≥ 30%：评估侧的低估可把 +3 压到 +2 附近；
- (b) 每个新物种的评估参考少于约 300 条：单物种的符号不稳；
- (c) 参考里 ab initio 模型很多（如蚜虫）：F 臂的"填背景"有一部分恰好是对的，训练侧的对比被削弱。

§2 的标准分别针对这三条：BUSCO 加证据比例针对 (a)，验证区段延长规则针对 (b)，ab initio 上限针对 (c)。另外，§4.8 预注册了只在"高置信参考"上看召回的敏感性分析。

### 1.3 简短回答

- 昆虫的注释不算完善。果蝇是人工精修的金标准；其他昆虫的 RefSeq 注释由 NCBI 自动合成、有 RNA-seq 证据，保守基因很完整（BUSCO 97–99%），非保守基因的质量随类群变化。蚜虫最弱，ab initio 模型占 8–12%。
- 会影响，但方向主要是让检验更保守。
  - 训练时漏注的真基因在两臂里都被当背景，是共同噪声；
  - 评估时 U 臂多报出的真基因会被算成假阳性，对 U 不利。
- 只要选注释证据充分的物种，并保证每个物种有足够多的评估基因，就不会凭空造出一个 U 优于 F 的结果。真正的风险是差值被压小或变得不稳定，所以用 §2 的标准把弱注释物种挡在外面。

## 2. 物种入选标准（建议值，待用户确认）

### 2.1 标准

阈值是在看过 NCBI 元数据之后、在看到任何昆虫模型输出之前定的。

| 编号 | 标准 | 建议值 | 理由 / 来源 |
|---|---|---|---|
| E1 | 组装 | RefSeq（GCF）当前版本，Chromosome 或 Complete Genome 级；基因组 ≤ 700 Mb；主染色体覆盖 ≥ 85% 的组装长度。主染色体规则同 M34：assembled-molecule、Primary Assembly、≥ 5 Mb，位置类型放宽为 Chromosome 或 Linkage Group（中华蜜蜂、小蠹的染色体以 Linkage Group 登记） | 控制数据量；保证大部分序列能进入抽样（方案 19 §1.1 第 5 条） |
| E2 | 注释来源单一 | 新物种只用 NCBI RefSeq EGAP 注释；老物种为果蝇（FlyBase，经 RefSeq 导入）和一个 EGAP 物种。不用提交者注释 | P4 只在新物种上评估，所以评估参考的口径完全统一 |
| E3 | 注释较新 | EGAP 软件版本 ≥ 10.0，且注释日期 ≥ 2022-01-01 | 新版 Gnomon，RNA-seq 量普遍更大 |
| E4 | 完整度 | NCBI 报告的 BUSCO（NCBI 所用谱系）完整度 C ≥ 97.0%。另在 ont 上用 insecta_odb10 对 10 个物种统一重算（每个基因取最长蛋白），C < 97.0% 的按 §2.4 替换 | 题目要求 insecta 口径；NCBI 多用目级谱系，口径更严，所以两者都看 |
| E5 | 证据支持 | fully-supported mRNA ≥ 94%；"> 5% ab initio" 的 mRNA ≤ 4%；报告列出 RNA-seq 量时须 ≥ 10 亿 reads | 直接衡量证据，针对 §1.2 的 (a)(c) |
| E6 | 基因长度与窗口 | 预筛：NCBI 报告的基因长度中位数 ≤ 6 kb。确认（ont CPU，§5）：eligible 基因中 CDS 跨度 > 24,064 bp（放不进 24,576 bp 核心窗口加两侧各 256 bp）的比例 ≤ 15% | 长基因只能部分监督，评估也更难；植物最高是椰枣的 4.8% |
| E7 | 系统发育 | 新物种之间、新物种与老物种之间科都不同；新物种至少覆盖 4 个目 | 避免同科近缘重复；与植物"目不重复"的做法相近 |
| E8 | 评估规模 | 每个新物种的验证区段 ≥ 400 条 CDS-assessable 主参考（规则见 §3.2） | 针对 §1.2 的 (b) |

**敏感性**：
- 若把 fully-supported 门槛提到 95%，Cloeon（94.6%）和蜂箱小甲虫（94.8%）会出局。蜉蝣目没有别的合格物种，新物种只剩 4 个目。
- 若把主染色体覆盖门槛提到 90%，赤拟谷盗（89.9%：11 号染色体 4.9 Mb，低于 5 Mb 门槛）会出局。

这两处是确认阈值时需要知道的。

### 2.2 选法（机械执行，规则先于结果）

1. **老物种**：
   - 黑腹果蝇（FlyBase，昆虫唯一的人工精修参考）；
   - 赤拟谷盗（鞘翅目模式种；它也是鞘翅目合格物种中 fully-supported 最高的，97.6%）。
2. **新物种的名额**：
   - 老物种没有覆盖的鳞翅目、膜翅目各 2 个；
   - 双翅目、鞘翅目各至少 1 个，且与老物种不同科；
   - 蜉蝣目 1 个，作为半变态、远缘的外群；
   - 第 8 个名额给鞘翅目。鞘翅目是物种最多的目，也只有它能在不同科里再挑出一个合格物种。双翅目的第二个候选是实蝇科，与果蝇同属无瓣蝇类（Acalyptratae），和果蝇较近。
3. **同目之内的排序**：
   - 先取通过全部标准的 Vipsania Insecta 测试种，便于以后在同一基因组上加 Vipsania 的 0% 注释参照点；
   - 再按 fully-supported 从高到低取，每科只取一个。

### 2.3 机械筛选结果

- 预筛条件：211 个染色体级 RefSeq 昆虫中，满足"≤ 700 Mb、NCBI 注释、2022 年后、BUSCO ≥ 97%"的有 121 个。
- 逐个读注释报告与序列报告后，40 个通过全部 E1–E6 预筛项：
  - 鞘翅目 4 个，双翅目 14 个，蜉蝣目 1 个，膜翅目 12 个，鳞翅目 9 个；
  - 半翅目 0 个：4 个蚜虫证据不足，烟粉虱基因过长；
  - 毛翅目 0 个。
- 81 个未通过的主要原因：fully-supported 不足 45 个，ab initio 超限 44 个，主染色体覆盖不足 33 个，RNA-seq < 10 亿 25 个，EGAP < 10.0 15 个，基因过长 11 个（一个物种可有多个原因）。
- 完整表格与脚本放在会话共享笔记目录 `insect-c2-20261104/`（`screen.tsv`、`report_quality.tsv`、`insecta_refseq.tsv`、`screen.py`），不入库。

### 2.4 替换规则（事前固定）

若某物种在 §5 的 CPU 核实中不达标（E4 的 insecta 重算、E6 确认、E8，或 §5.3 的其他门槛），按下列顺序替换，不得改动其他物种：

- 先用同目备选：
  - 双翅目 → 橄榄实蝇 *Bactrocera oleae*（`GCF_042242935.1`，Tephritidae，fully-supported 96.9%）；
  - 鳞翅目 → 草地贪夜蛾 *Spodoptera frugiperda*（`GCF_023101765.2`，Noctuidae，96.5%）→ *Vanessa tameamea*（Nymphalidae，94.9%）；
  - 膜翅目 → *Hylaeus volcanicus*（`GCF_026283585.1`，Colletidae，97.0%）→ *Neodiprion virginianus*（Diprionidae，96.1%）。
- 鞘翅目、蜉蝣目没有合格的同目备选，依次用全局备选：橄榄实蝇 → 草地贪夜蛾 → *Hylaeus volcanicus*。已用过或违反 E7 的跳过。
- 替换后新物种数 n 不变；若无可替换，n 减少，判据的同向数相应改为 ⌈0.75 n⌉。

## 4. 预注册协议（M39；执行期间不得根据结果修改，修改须在 §4.12 追加记录）

### 4.1 问题与判据

- **P4-I（主判据）**：
  - 两臂各取 §4.6 选定的检查点，在 8 个新物种的内部验证区段上算 pooled exact-chain F1，要求 k50U − k50F ≥ +2.0 点，且 8 个新物种中至少 6 个的 k50U − k50F > 0；
  - n 个新物种时为 ⌈0.75 n⌉ 个，差值恰为 0 不算同向；
  - 打分口径同 M34：M31 `c1_val`，参考为区段内完整的 CDS-assessable 主参考，预测 CDS ≥ 96 bp，不做后验过滤。
- **结论的写法（预先固定）**：
  - 两条都满足：**成立**，写为"C2 的优势在昆虫上复现（NT-v2，单 seed）"；
  - 0 < pooled < +2.0 且同向数达标：写为"方向一致、幅度未达判据"；
  - pooled ≥ +2.0 但同向数不达标：写为"汇总达标但物种间不一致"；
  - 其余情况（pooled ≤ 0 等）：写为"未复现"。
  - 后三种都算 P4-I 不成立。
- **8 个物种 vs 6 个物种的理由**：
  - 设每个物种 U 优于 F 的概率为 0.885（相当于真实差值约 +3、单物种噪声标准差约 2.5，粗估）。
  - "≥ 6/8"成立的概率约 0.94，"≥ 5/6"约 0.86。
  - 新物种数不影响训练步数，只略增验证时间。
- **描述量（不设门槛）**：
  - D1：各新物种的 k50U − k50F（与报告 20 §13 同表）；
  - D2：pooled 差的按基因配对自助法 95% CI（2,000 次，seed 0，在 8 个区段的参考基因与预测上同步重采样）；
  - D3：精确率 / 召回 / 预测数分解（植物上的差距主要在召回）；
  - D4：按外显子数分层（1 / 2–5 / ≥ 6）；
  - D5：老物种留出染色体 D 上的 k50U − k50F（复现植物 DEV 上"填背景也拖累全标签物种"的观察，−1.29）；
  - D6：若有 T 臂，报告 k50U − T、k50F − T（植物为 −1.76、−5.00）。

### 4.2 数据划分

| 集合 | 内容 | 用途 |
|---|---|---|
| 训练 | 老物种的训练染色体；新物种除验证染色体外的全部主染色体 | 抽样 |

| 新物种验证区段 | 8 个区段（§3.2） | P4-I；每个停点都评，只作报告，不参与选点 |

| 弃用 | 新物种验证染色体的剩余部分；果蝇 4 号与 Y；各物种 < 5 Mb 的序列、未定位序列、细胞器 | 不读取 |

### 4.3 模型与配方（沿用 M31 B 与 M34 `ntv2` 后端，逐项）

- **编码器与特征**：NT-v2-500M-multi-species，FP32 权重 + BF16 autocast；hidden_states 21 + 27 拼接；
- **窗口**：12,288 bp，步长 6,144；
- **头**：`M28Core('C0', 2048, 128)`；
- **LoRA**：q/v，rank 8、alpha 16，块 13–27；
- **优化器**：AdamW；头 lr 峰值 1e-4、LoRA 3e-4，cosine 到 1e-5，5% warmup，裁剪 1.0；batch 8；
- **损失**：配分函数 CRF（精细标签硬约束 + ε = 0.1 粗通道 + 未知位置边缘化 + 128 外显子）；DP 并行 12 进程；
- **几何**：24,576 bp 核心加两侧各 12,288 bp 邻窗。
- **头的初始化（2026-11-04 已确认）**：
  - 同 M34 `ntv2` 后端，用 M31 runA `model_002048.pt`。这个头是在拟南芥、水稻上冻结 NT-v2 训练的；
  - 所有臂共享，是常数偏移，不影响 U − F，但意味着昆虫模型带有植物上学到的初始头，论文须写明；
  - 备选：在果蝇和赤拟谷盗上先做一次冻结编码器的 A 阶段（2,048 步，约 12 GPU h），得到纯昆虫的初始头。因为本实验是"简单尝试"，不推荐。
- **语法适用性**：M28 语法的最小内含子 5 bp、最多 128 个外显子；昆虫常见的约 50–60 bp 短内含子在语法上可行。是否有基因超过 128 个外显子，由 §5 核实。

### 4.4 步数与 sampler

- **步数**：3,072 步（24,576 次抽样），每 768 步存模型；cosine 定义到 3,072，不早停。
- **sampler**（同 M34，seed 1）：
  - 每次抽样先按物种等权选物种（10 个物种，各 10%）；
  - 再以 50% 概率在该物种全部（训练 contig、链、24,576 bp 网格窗口）中均匀选窗口，50% 概率"基因优先"：均匀选一个已标注 eligible 基因，再在覆盖它的 ≤ 5 个窗口中均匀选。
- **U 与 F 共用同一抽样序列**：抽样只依赖物种集合和标注集合，不依赖 U / F。

### 4.5 臂

| 臂 | 老物种标注 | 新物种标注 | 未选基因处理 | 目的 |
|---|---|---|---|---|
| **I10_k50U** | 100% | 50% | U：未选中 eligible 基因的 CDS 外包区间在细、粗标签里都标为未知，损失中边缘化 | 主臂 |
| **I10_k50F** | 100% | 50% | F：当作不存在，标为背景 | 主臂 |

  - 每个新物种的训练染色体上，eligible 基因按（contig, 起点, id）排序；
  - 用 seed 20261017 生成固定排列，取前 ⌈0.5 n⌉ 个；
  - 按基因抽，不按窗口或区段抽。
- 老物种始终全标签。

### 4.6 内部验证与检查点选择

- 每 768 步（768 / 1536 / 2304 / 3072）在选点集合和 8 个新物种验证区段上推理，并做整区域精确 skyline 解码。
- 最终检查点 = {1536, 2304, 3072} 中选点集合（果蝇 2R + 赤拟谷盗 6 号）pooled F1 最高者，并列取步数大者。所有臂同一规则，选点不看新物种区段。
- **植物上的教训（报告 20 §13）**：同步数的 k50U − k50F 在停点间摆动很大（+39.3 / +6.12 / −3.95 / +3.24）；若 k50F 选的是 2,304 步，P4 就不成立。因此预先规定：
  - 4 个停点的同步数差值全部报告（稳健性 R1）；
  - 判定只看选定检查点，不因摆动改判。

### 4.7 老物种留出染色体 D 的使用

每臂只对选定检查点评一次（果蝇 X + 赤拟谷盗 7 号，约 42 Mb），设单次哨兵，模型 md5 不一致即拒绝。它只用于描述量 D5，不参与选点，也不参与 P4-I。

### 4.8 稳健性与敏感性（描述性，预先登记）

- **R1**：同步数（768 / 1536 / 2304 / 3072）的 pooled 差值与同向数。
- **R2**：高置信参考子集上的召回差。子集为新物种区段中，RefSeq mRNA 的 `model_evidence` 属性显示"100% coverage by RNAseq alignments"且"support for all annotated introns"的参考基因。这个子集几乎不受漏注和错误模型影响，比较两臂在其上的召回。精确率无法用同样办法纠正，列为局限。
- **R3**：可能是漏注真基因的假阳性。
  - 在各臂的假阳性中，找出与任何已注释基因（同链）都不重叠的预测；
  - 翻译后用 DIAMOND 比对两个老物种的蛋白组（e ≤ 1e-10，query 覆盖 ≥ 50%）；
  - 报告有命中的条数，粗估 U 臂多出的假阳性里有多少可能是参考漏注。
- **R4**：逐物种差值与该物种 fully-supported 比例、RNA-seq 量的对照表。只有 8 个点，不做检验。

### 4.9 单 seed 的局限

- 每臂只有一个 seed：抽样 seed 1；LoRA 初始化与头的初始化同 M34 `ntv2`。植物 P4 同样是单 seed。
- 植物 T2 的 +2 seeds 只给出 T2 自身的 seed 方差（报告 20 §14：早期停点相差很大，2,304 步只差 0.44），不能直接套用到 U − F 的差值上。
- **接近阈值规则（预先固定，正反两个方向对称）**：
  - 若选定检查点的 pooled 差值落在 [+1.0, +3.0] 内，结论加注"接近阈值，单 seed 不足以定论"，并建议补一对 seed（`sampling_seed` 2、`lora_seed` 2 的 k50U 与 k50F，约 50 GPU h，须用户另行批准）；
  - 补跑后，用两个 seed 的平均差值与平均后的逐物种方向重新套用 P4-I；
  - 不补跑则维持单 seed 的判定和加注。
- 本实验同时换了骨干（植物 P4 用的是 PlantCAD2，这里用 NT-v2）和类群。若不成立，无法区分是骨干还是类群的原因；在植物上用 NT-v2 跑一对 k50U / k50F 可以区分，约 50 GPU h，不在本协议内。

### 4.10 预期（猜测，非承诺）

- 植物上 P4 的差值主要来自召回：F 臂学会了少报基因。没有理由认为这个机制在昆虫上不同。
- 但 NT-v2 的绝对精度比 pc2 低（植物 DEV 上约低 9 点），差值可能被整体压低；评估侧的保守偏差（§1.2）也会让差值偏小。
- 没有依据预测具体数值。

### 4.11 统计

- 主判据只用点估计与同向计数，与植物 P4 相同。
- D2 的自助法 CI 只作描述。
- 多个描述量不做多重比较校正；只有 P4-I 是确认性终点。

    - 每一步完成后跳过（以 SMOKE_OK / ARM_DONE 为准），全部完成后写 `M39_GPU_DONE`，事件写入 `run_all.jsonl`。
    - 它不检查其他 GPU 任务，只能由队列在 k25U 结束后启动。
  - 训练与推理复用 M34 的 supervise / infer_retry 逻辑（GPU 空闲显存不足即等待，OOM 后自动恢复），CPU 绑定同 M34（`M39_CPUS`，默认 2,4,…,16–24）。
  - P4-I 的汇总脚本（逐物种差值、按基因配对自助法 D2、R1–R4）尚未写，在 GPU 结果出来之前补上；它只读 `metrics.jsonl` 与预测 GFF。

### 5.2 能否直接复用 M34 代码（读代码的结论）

**不能原样跑，但改动都在常量和登记层，标签与掩码逻辑可以原样复用。** ont 上 M34 的队列（T2_s3、k25U）正在使用这些文件，所以**不改 M34 原文件**，而是复制到 `experiments/M39-INSECT-C2/scripts/` 再改。

| 模块 | 能否复用 | 需要的改动 |
|---|---|---|
| `m34_labels.Labeler`（FULL / U / F 目标、eligible 判定、主转录本目录、窗口行） | **逻辑原样复用** | 复制后只换它导入的常量模块。依赖的冻结函数（`common_ruler.select_reference`、`manifest.chain_checks`、`build_targets`）与物种无关；但须在果蝇的 NCBI GFF（由 FlyBase 导入）上核实 `protein_coding_only` 的解析结果（§5.3 V3） |

| `m34_train_common` / `m34_train_lora.py` | 需改 | `VAL_REGIONS_LEGACY` 写死为拟南芥、水稻的染色体，改为果蝇 2R、赤拟谷盗 6 号；`register()` 目前只把新物种的验证伪 contig 登记进冻结的 `m29_common`，要扩展为同时登记老物种的 S、D 染色体（它们不在 m1_screen 里）；`INIT` 沿用 M31 runA |

### 5.3 必做的 CPU 检查与门槛

| 编号 | 检查 | 门槛 / 处理 |
|---|---|---|
| V1 | md5 全部一致；装配报告推出的主染色体、S、D、验证染色体与 §3.2 一致 | 不一致则按规则重算并记录 |
| V2 | 每个物种的目录统计：主编码基因数、CDS-assessable 数、eligible 数与比例、非标准剪接比例、`CDS_partial` 数 | eligible / assessable < 90% 或非标准剪接 > 5% 时，按 §2.4 替换（植物上薯蓣为 10.8%，当时保留并作为观察对象；昆虫事前收紧） |
| V3 | 果蝇：NCBI GFF（FlyBase 导入）解析出的蛋白编码基因数应与 13,962 同量级；统计终止密码子通读、非 AUG 起始等被判不可用的基因数 | 记录；只影响老物种 |
| V4 | **NT-v2 窗口覆盖**：eligible 基因的 CDS 跨度分布，分 ≤ 12,288（落在一个编码器窗口内）、≤ 24,064（能作完整正例）、≤ 49,152（核心加上下文）、> 49,152 四档；外显子数 > 128 的基因数；内含子 < 20 bp 的数量 | E6：跨度 > 24,064 的比例 ≤ 15%，否则替换；外显子 > 128 只记录（语法上限，标为未知） |
| V5 | CPU DP 干跑（`m34_cpu_dp_check.py` 的同款）：每个物种外显子最多与 CDS 跨度最长的基因各取压力窗口，加真实抽样窗口，随机势下 InfeasibleObservation 计数 | 必须为 0 |
| V6 | 验证区段：按 §3.2 算出 L、区段内参考数、区段的 GFF 子集 | E8：< 400 条则替换；坐标与 md5 写入 §4.12 |

| V8 | 调度：3 个臂的抽样表；U / F 共用同一表；不含禁用 contig；物种计数在等权二项分布的 5σ 内；各臂标注基因数 | 写入 §4.12 |

| V10 | 中华蜜蜂的 RNA-seq 量（新版报告页不显示） | 若可查到且 < 10 亿则按 E5 替换；查不到则记"未知" |

## 7. 风险与局限

1. **参考注释**：见 §1。评估偏保守；漏注和错误模型的比例无法直接测，只能用 R2、R3 间接估计。
2. **骨干与类群同时变化**：见 §4.9 最后一条。
3. **单 seed**：见 §4.9。
4. **头的初始化来自植物**：见 §4.3。
5. **评估基因少**：靠 §3.2 的延长规则缓解；单物种的符号仍会比植物更不稳。
6. **长基因**：昆虫基因长度的中位数是植物的 1–2 倍，CDS 跨度超出窗口的基因更多。两臂一样受影响，但会压低绝对 F1，也会增加噪声。
7. **暴露**：果蝇本种在 NT-v2 预训练内，但它只作老物种；新物种中有 3 个只在科级有暴露。
8. **代码**：M39 是 M34 的复制改写，需要新测试；`ntv2` 后端在 M34 路径上未上过 GPU。
9. **多重比较**：只有 P4-I 是确认性终点，其余都是描述。

## 8. 需要用户确认的点（2026-11-04 已全部按草案确认，见 §4.12）

1. **入选阈值**（§2.1）：主染色体覆盖 ≥ 85%；EGAP ≥ 10.0 且 2022 年后；BUSCO（NCBI 谱系）≥ 97%，insecta_odb10 重算 ≥ 97%；fully-supported ≥ 94%；ab initio ≤ 4%；RNA-seq ≥ 10 亿 reads；基因长度中位 ≤ 6 kb，CDS 跨度超窗比例 ≤ 15%；验证区段 ≥ 400 条（目标 500 条）。注意 §2.1 的两处敏感性：fully-supported 提到 95% 会去掉蜉蝣目；覆盖门槛提到 90% 会去掉赤拟谷盗。
2. **物种名单**（§3.1）：老物种为果蝇、赤拟谷盗；新物种为按蚊、家蚕、印度谷螟、中华蜜蜂、切叶蚁、云杉八齿小蠹、蜂箱小甲虫、Cloeon；替换顺序见 §2.4。若想更省，可减到 6 个新物种（去掉印度谷螟和蜂箱小甲虫），判据随之改为 ≥ 5/6，检验力会下降（§4.1）。
3. **是否加 T 臂**：建议加，排在两臂之后，约多 25 h（上限 40 h）。它不影响 P4-I，但植物上最好懂的数字正是"相对全标签各损失多少"（−1.76 对 −5.00）。
4. **头的初始化**：建议沿用 M31 runA（植物上训练的头，零额外 GPU）；备选是先在昆虫上做 A 阶段（约多 12 GPU h）。

用户确认后：在 ont 上做 §5 的 CPU 准备（不占 GPU），把坐标和计数写进 §4.12，然后等 k25U 结束后跑 smoke 与正式臂。
