# 23 M37-JOINT-DECODE-SMOKE 预注册协议：多装配联合解码的前提检验（2026-10-21）

写于任何 M37 输出产生之前。目的只有一个：**用最少算力回答"同一物种不同装配/单倍型之间，模型的错误是否独立、共享证据是否能纠错"**。回答为否则多装配联合解码不立项；为是才写完整协议（M37 正式版）。

用户决定（2026-10-21）：多装配联合解码先做 smoke；不打断 M35/M34 的 GPU 顺序。

## 0. 想法

泛基因组里同一基因在 N 个装配上各出现一次。现有工具逐装配独立注释。若模型在装配 A 上漏掉的基因在装配 B 的同源位点被正确解码（反之亦然），那么把各装配的逐碱基角色势通过全基因组比对投射到同一坐标、合并后再解码（"联合解码"），就能纠错。这是集合后验框架天然支持的（势是可加的），Carbon-A/ANNEVO 的 Viterbi 也能做，但没有人做过。smoke 只测前提，不测完整方法。

## 1. 数据（只用水稻，两条同源染色体）

- 装配 A：*Oryza sativa* Nipponbare AGIS-1.0（GCF_034140825.1，已在 ont `data/m1_screen/oryza_sativa`），**只取 M31 内部验证染色体 NC_089044.1**（TRAIN 留出、非 DEV、有 M26 CDS-assessable 参考；M33 已对其推理过，可复用势）。不碰 DEV（NC_089041.1）。
- 装配 B：一个**不同品种**的染色体级装配，须在 NCBI 有 GenBank/RefSeq 注释（用于 B 自身评分与同源位点核对）。按优先序选第一个满足"染色体级 + NCBI GFF 中蛋白编码基因 ≥ 30,000"的：Minghui 63（MH63RS3）> Zhenshan 97（ZS97RS3）> Shuhui 498（R498）> 9311。只下载与 NC_089044.1 同源的那条染色体（按染色体编号对应，再用比对确认）。记录 accession、md5、下载时间。
- 若所有候选都无 NCBI 注释，退一步用 IRGSP-1.0 Nipponbare（GCF_001433935.1）同号染色体，并在报告里写明这只能测"装配差异"而非"单倍型差异"。

## 2. 模型与推理

- 模型：M31 B（NT-v2+LoRA，`outputs/M31-C1-NTV2/runB/model_001536.pt`，md5 4a89a856…），冻结，不训练。
- 推理：`m33_infer.py` 路径（保留 15 角色势 `pot/*.npy`），对 A 的 NC_089044.1（若 M33 已有势文件则直接复用，不重算）与 B 的同源染色体各推理一次。GPU 约束：**仅当 ont 空闲显存 ≥ 8 GB 且单次 ≤ 20 分钟**；本模型峰值 2.2 GB。M35 正在跑，允许共存（M32 smoke 与 M31 共存的先例），但 CPU 解码进程绑定核 24–31、nice，不超过 4 个。
- 解码：整 contig 精确 skyline（`c1_infer`/`c1_val` 的冻结函数）。

## 3. 比对与投射

- minimap2（装到独立 env，如 `~/envs/m37` 或 `pip install mappy` 到 `~/envs/m37_extra`，不动既有 env）：`minimap2 -cx asm10 --cs A_chr B_chr`。
- 从 `cs` 标签建碱基级映射 A↔B，只保留 identity ≥ 90% 且长度 ≥ 1 kb 的比对块；倒位块映射时角色势按链翻转（正负链势互换并反转位置）。记录可映射碱基比例。

## 4. 分析（全部 CPU）

**4.1 错误独立性（主分析，无需联合解码）**
对 A 的每条 CDS-assessable 参考链：A 单独解码是否精确命中；把 B 的单独解码链投射到 A 坐标后是否精确命中同一参考（仅对完全可映射的参考计）。得到 2×2 表。
- **headroom** = A 漏检中"B 投射命中"的比例。
- 对称方向（B 参考，A 投射）若 B 注释可用则同样报告。

**4.2 势平均联合解码**
pot_A' = (1−λ)·pot_A + λ·proj(pot_B)（仅可映射碱基；不可映射碱基保持 pot_A），λ ∈ {0.25, 0.5}；skyline 解码 A；按项目 ruler 评 exact-chain F1，与 A 单独解码做 1 Mb 块配对 bootstrap（2,000 次）。另记 CDS 碱基 F1、背景负担、按段数分层。

**4.3 描述性**：A 与 B 序列不同的位置（SNP/indel 密度）与纠错位点的关系；可映射参考占比。

## 5. 判据（先于结果固定）

| 结果 | 判定 |
|---|---|
| headroom ≥ 20% 且 λ 任一取值下 ΔF1(A) ≥ +1.0、配对 CI 下界 > 0 | **GO**：写 M37 正式协议（多装配、一致性先验、泛基因组应用） |
| headroom ≥ 20% 但 ΔF1 < +1.0 | 前提成立、合并方式不对：只允许再试一种合并（如按后验加权或一致性约束解码），仍不行则放弃 |
| headroom < 20% | **NO-GO**：错误在单倍型间共享，联合解码无空间；方向放弃，泛基因组只保留"一致性/PAV 不确定性"应用 |

## 6. 成本

GPU ≤ 30 分钟（B 染色体推理；A 复用 M33 势）。CPU：比对 < 5 分钟；解码 3–4 次（A 单独、B 单独、λ 两档）每次约 15–25 分钟（4 worker）；bootstrap 几分钟。总计半天内。
