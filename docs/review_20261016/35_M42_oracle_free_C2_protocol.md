# 35 M42-ORACLEFREE-C2：不借真值的不完整注释训练（关卡 0 / 关卡 1 预注册协议；草案 2026-11-23，待用户过目）

依据：`docs/presubmission_plan_20261123.md`（用户 2026-11-23 决定走路线 B，关卡 0 与关卡 1 都做）。本协议在下载任何目标物种注释之前写定；修改只能在 §9 追加，并注明当时已看过什么。

## 0. 问题

C2 目前的证据（M30、P4）里，"未知"位置由完整注释定出（报告 19 §3.10，上界设定），而且植物上部分标签相对零标签模型几乎没有净增益（T2 68.84 对 k50U 67.86 / 69.03）。本实验问：

> 只给一个物种**真实的旧版注释**和**当时可得的跨物种证据**，不借助任何新版信息，部分观测训练（U）能否让模型在该物种上比零标签模型（Z）和一个合理的非结构化对照（L）更好，并找回旧版漏掉、新版补上的基因？

## 1. 目标物种（规则先于数据）

**候选条件**（全部满足）：
1. 被子植物，NCBI RefSeq，染色体级装配，基因组 ≤ 1.5 Gb；
2. 同一装配 accession.version 上至少有两次 RefSeq 注释（旧版、新版）；装配版本不同的物种不入选；
3. NCBI 注释报告的"与上一版比较"里，新版新增（new）蛋白编码基因 ≥ 300；
4. 不在 T2 / T10 的 10 个训练物种、set B（Dryas、Eschscholzia）、独立面板核心 10 种、M36 目标物种之中；
5. 记录是否在 PlantCAD2 预训练的 65 个基因组中（不排除，但排序时不在预训练中的优先）。

**排序与选取**（机械执行）：在满足条件的候选里，先按"是否不在 PlantCAD2 预训练中"（是优先），再按新增蛋白编码基因数降序，取第 1 名作**开发物种**；与开发物种不同目的第一名作**确认物种**（关卡 2 才用）。并列时取新版发布日期较近者。

**只读哪些信息来选物种**：NCBI 注释报告页的汇总计数与日期。新版 GFF 可以下载，但在 §3 的掩码冻结、并记录其 md5 之前**不打开、不解析**。

## 2. 数据与划分

- 基因组：该装配的 RefSeq FASTA（保留 NCBI 的软屏蔽小写）。
- 旧版注释：训练用的唯一标签来源。
- 新版注释：只用于 §4 审计（掩码冻结之后）和关卡 1 的评分。
- 留出：按装配顺序的**最后两条主染色体**只用于评分，不进训练、不参与生成证据或掩码以外的任何选择（掩码在这两条上也生成，用于审计）。
- 基因资格同 M34：CDS 完整（有起止）、CDS ≥ 96 bp、主转录本。

**新版相对旧版的基因分类**（掩码冻结后才计算）：
- **新增位点**：新版基因的 CDS 与旧版任何基因的 CDS 都不重叠（同链）；
- **结构修订**：与旧版某基因 CDS 重叠但 CDS 链不同；
- **相同**：CDS 链完全一致；
- 新版中被删除的旧版基因单独计数。
主终点只用"新增位点"；结构修订单独报告。

## 3. 掩码规则（在打开新版之前冻结）

**证据**：miniprot 把 M34 十个训练物种的 RefSeq 蛋白（同 M36 S2，ont `data/m34_train`，跨物种、不含目标物种自身蛋白）比对到目标基因组。保留比对覆盖 ≥ 50%、identity ≥ 40% 的命中（比 M36 S2 的完整模型筛选宽，因为这里只用于圈"可能有基因"的区域）。命中与旧版基因 CDS 同链重叠的丢弃。

**三态标签**：
- **正例**：旧版所有合格基因的完整结构（细标签硬约束，同 M34）。
- **未知**：证据区域向两侧各扩展 E = 2,000 bp 后的并集，减去正例。
- **背景**：其余位置。
- 另外两个变体只用于 §4 审计，不训练：E = 0 与 E = 5,000；以及"未知 = 全部非正例位置"（全边缘化）。

说明：背景里仍可能有没有证据的真实基因，这正是本实验要检验的现实条件；我们不用"没有证据"之外的任何信息去挑负例，也不用新版。

**冻结**：掩码以 BED 形式写出，记录 md5、生成命令与软件版本，提交到仓库后，才允许打开新版 GFF。

## 4. 关卡 0：掩码审计（0 GPU）

掩码冻结后打开新版，按 §2 分类，计算（全基因组与留出两条染色体分别报告）：

| 指标 | 定义 |
|---|---|
| 新增位点数 | 新版相对旧版的新增蛋白编码基因 |
| 新增位点被未知覆盖率 | 新增位点 CDS 碱基落在未知区的比例；以及"整条 CDS 链完全落在未知区"的位点比例 |
| 未知区占比 | 未知区占全部非正例碱基的比例 |
| 随机对照 | 与未知区同长度分布、随机平移的区段对新增位点的覆盖率（1,000 次） |
| 背景里的新增位点 | 新增位点 CDS 落在背景（会被当负例训练）的比例 |

**关卡 0 通过条件**（全部满足才进关卡 1）：
1. 留出两条染色体上新增位点 ≥ 30 个（否则评分无意义，换下一个候选物种，记录原因）；
2. 主掩码（E = 2,000）下，全基因组新增位点"整条 CDS 落在未知区"的比例 ≥ 40%；
3. 该比例至少是同长度随机掩码的 2 倍；
4. 未知区占非正例碱基 ≤ 30%。

不通过时不训练：按 §1 换下一个候选（最多换两次），仍不通过则报告"跨物种蛋白证据不足以定位漏注基因"，关卡 1 改为讨论是否加 RNA-seq 证据（另行决定）。

## 5. 关卡 1：512 步小试（GPU）

**初始化**：终版 T2（PlantCAD2 + LoRA，step 2304）。**配方**：同 M36 协议 22 §3（512 步，batch 8，头 lr 5e-5、LoRA lr 1e-4，cosine 至 1e-6，5% warm-up，clip 1；窗口抽样"正例优先 + 均匀"各半；主结果取 step 512，不做检查点选择）。各臂共用同一抽样序列与同一初始化。

| 臂 | 训练目标 | 看到的信息 |
|---|---|---|
| Z | 不训练（T2 直接推理） | — |
| F | 配分函数 CRF；旧版之外全部当背景 | 旧版 |
| U | 配分函数 CRF；§3 三态，未知位置边缘化 | 旧版 + 证据掩码 |
| L | 逐位置交叉熵，只在正例与背景位置计算，未知位置不算；推理用同一个 CRF 解码器 | 旧版 + 证据掩码（与 U 相同） |

（结构化硬补全 H 与 nnPU 放到关卡 2。L 需要在训练器里新增一个损失分支，代码改动先在 CPU 上测试。）

**评分**（留出两条染色体，新版为参考，口径同 M34：exact CDS chain，CDS ≥ 96 bp，不做后验过滤）：
- 整体 exact-chain F1、精度、召回、预测数；
- 新增位点的完整链召回（另按"有 / 无证据覆盖"分开）；
- 同时报告以旧版为参考的 F1（描述）。
- 配对差的 CI：按基因重采样 2,000 次（seed 0）。

**关卡 1 通过条件**（开发物种，单 seed，只作继续 / 停止信号）：
1. U − Z 整体 F1 ≥ +1.0；
2. U − L 整体 F1 > 0；
3. 新增位点完整链召回：U > Z；
4. U 的精度不低于 Z 超过 2 个点。

全部满足 → 关卡 2（确认物种 + 加 H 臂 + 正式步数，另写方案交用户定）。否则停止，按"C2 只在已知缺失位置的上界设定下成立"写论文（路线 A），本实验结果完整报告。

## 6. 算力与地点

- **关卡 0**：本地 Mac（M4，10 核）。下载 FASTA / GFF / 蛋白，miniprot 比对约 1–2 h，审计脚本几分钟。硬盘只剩约 37 GB，只放一个物种。不占 ont（TE 计时期间）与 win3090（TE 的 CPU 任务在跑）。
- **关卡 1**：约 3 臂 × 512 步（M36 实测每臂 5–6 h，含推理）≈ 15–20 GPU h（4090）。优先 ont 恢复后跑；若关卡 0 完成时 ont 仍暂停，用 CAU 超算 ChaoBaiHe 4090（2.4 元 / 卡时），估计 35–65 元（含环境搭建与冒烟），提交前向用户报确切预算。不用 Baobab（12-01 前冻结）、不用 Modal。win3060（RTX 3060 笔记本，6 GB 显存、桌面已占约 1.5 GB）不足以跑 PlantCAD2 + LoRA 训练（M41 训练实测约 5 GB），不用。

## 8. 风险

- 新旧版差异可能主要来自 NCBI 流程更新，而不是新证据；本实验只检验"旧版 + 跨物种证据"能否学到新版补上的基因，不评价 NCBI 流程。
- 新版本身也不是真值；新增位点里可能有假基因。关卡 2 再加独立证据核验。
- 跨物种蛋白证据偏向保守基因；"无证据覆盖"的新增位点很可能找不回，报告时分开写。
