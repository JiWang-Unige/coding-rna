# 35 M42-ORACLEFREE-C2：不借真值的不完整注释训练（关卡 0 与关卡 1 预注册协议；2026-11-24 草案）

写于任何 M42 数据下载、掩码生成或训练之前。用户决定（2026-11-23，`presub-route`）：走路线 B，关卡 0 与关卡 1 都做；"批准执行"（2026-11-24）。背景与动机见 `docs/presubmission_plan_20261123.md` §1、§3。修改只能在 §9 追加记录，并写明当时是否已看过任何新版注释或模型输出。

## 0. 问题

已有的 C2 证据（M30、P4）都用完整注释定位被删的基因，再把那些位置标为未知（报告 19 §3.10 的"上界设定"）。真实情况下，研究者只有一份不完整的旧注释，不知道漏在哪里。M42 回答：

> 只给模型真实的旧版注释和可公开获得的跨物种证据，部分观测 CRF（U）训练能否比 (a) 不在目标物种上训练的零标签模型（Z）、(b) 同样信息下的逐位置屏蔽损失（L）、(c) 把未注释处当背景（F）更好地重建新版注释中的完整基因，尤其是旧版漏掉的基因？

相关的已有阴性结果：M36（报告 27）在 Dryas / Esch 上用自训练或蛋白证据做种子、512 步适配，七个臂全部比零样本差 1.5–7.7 点；原因之一是种子链约四分之一是错的。M42 与 M36 的关键区别是正例来自人工整理过的旧版 RefSeq 注释，而不是模型自己的预测或蛋白比对。

## 1. 物种选择（规则先于数据）

**数据来源**：NCBI 真核基因组注释（Eukaryotic Genome Annotation Pipeline）的历史版本，`https://ftp.ncbi.nlm.nih.gov/genomes/all/annotation_releases/<taxid>/<release>/`，以及每个版本的注释报告（Annotation report）。

**入选条件（全部满足）：**
1. 被子植物；不属于本项目已用过的任何物种：T2 / T10 的 10 个训练物种、set B（Dryas、Eschscholzia）、独立面板全部物种、M36 / M37 用过的物种。
2. 同一个装配（accession 与 version 都相同，如 GCF_xxx.1）上有至少两个 RefSeq 注释版本，旧版比新版早至少 12 个月。
3. 新版注释报告里"相对上一版新增的基因"（new genes）中，蛋白编码基因 ≥ 300 个。只看报告里的汇总数，不下载新版 GFF。
4. 染色体级装配，总长 ≤ 1.5 Gb（算力）。

**排序与指派：**
- 按与拟南芥、水稻的目（order）是否相同分两档：不同目的优先。
- 同档内按新增蛋白编码基因数从多到少排。
- 第一名为**开发物种 D1**（关卡 0、关卡 1 都用）；与 D1 不同目的最高名为**确认物种 D2**（只在关卡 2 用，关卡 0 只做数据可得性检查，不做掩码审计）。
- 记录每个候选是否在 PlantCAD2 预训练的 65 个基因组里（只记录，不排除；在预训练里会抬高 Z，使检验偏保守）。
- 若没有物种满足条件 3，把门槛降到 ≥ 150 个，在 §9 记录；仍没有则 M42 停止，回报用户。

## 2. 数据划分（每个目标物种）

- 主染色体按长度降序编号，奇数位为**训练集 A**，偶数位为**评估集 E**。E 只在关卡 1 最终评分时读取新版注释；A 上的新版注释在任何阶段都不读取。

## 3. 关卡 0：三态监督与掩码审计（只用 CPU）

### 3.1 正例

旧版注释中满足以下条件的蛋白编码基因（每个基因取 NCBI 标注的代表转录本；没有则取 CDS 最长的转录本）：起始与终止密码子完整、CDS 总长 ≥ 96 bp、无内部终止、剪接位点合法（GT-AG、GC-AG、AT-AC）、不跨装配缺口。只用旧版本身的信息过滤，**不与新版比较**。

### 3.2 证据

- 蛋白：M34 十个训练物种的 RefSeq 蛋白（与 M36 S2 同一来源，已在 ont `data/m34_train`），用 miniprot 比对到目标基因组。不使用目标物种自己的蛋白。
- 证据命中：miniprot 比对的蛋白覆盖度 ≥ 50%、一致度 ≥ 40%。这比 M36 S2 的种子标准（覆盖 ≥ 95%、一致度 ≥ 70%）宽，因为这里只用来划"未知"，不当正例。
- RNA-seq 第一轮不用。
- 时间问题：这些蛋白可能晚于旧版注释，NCBI 生成新版时也可能用过它们。M42 的问题因此表述为"旧注释 + 跨物种蛋白证据下的注释更新"，不表述为"只凭旧注释"。

### 3.3 三个掩码变体（审计前冻结）

在训练集 A 上，正例以外的位置分为"未知"或"背景"：

| 变体 | 未知 | 背景 |
|---|---|---|
| V1 证据窄 | 证据命中的基因组跨度向两侧各扩 2 kb | 其余 |
| V2 证据宽 | 证据命中跨度各扩 10 kb | 其余 |
| V3 全未知 | 正例以外全部 | 无（只有正例约束） |

- 正例基因的内含子和正例两侧 1 kb 不设未知（保持与 M34 相同的基因边界约束）。
- 另做两个只用于审计、不用于训练的参照：
  - **R 随机**：与 V1、V2 各自同覆盖率的随机区段掩码（区段长度分布与证据区段相同，seed 20261124）；
  - **O 真值**：用新版注释定位旧版缺失基因再标未知（即原来 P4 的做法），代表上界。

### 3.4 审计指标（只在训练集 A 上，读新版注释）

新版基因与旧版基因按 CDS 重叠配对，分为：
- **新增位点**：与旧版任何基因的 CDS 都不重叠的新版蛋白编码基因；
- **结构修订**：与旧版基因 CDS 重叠但完整链不同；
- **相同**：完整链一致。
（装配相同，坐标直接可比。）

对每个变体报告：
1. 新增位点数；
2. 新增位点的 CDS 碱基落在未知区的比例，以及整个位点完全落在未知区的比例（后者决定 CRF 里那条真实路径是否被允许）；
3. 未知区占训练集 A 非正例碱基的比例；
4. 正例覆盖了多少新版"相同"基因（旧正例的保留率）；
5. 同覆盖率随机掩码 R 的上述第 2 项；
6. 新增位点中有、无证据命中的数量。

### 3.5 关卡 0 → 关卡 1 的放行规则（机械执行）

- 候选变体 = V1、V2 中满足"新增位点完全落在未知区的比例 ≥ 同覆盖率随机掩码的 2 倍"且"未知区 ≤ A 中非正例碱基的 30%"的变体。
- 若两个都满足，取新增位点完全覆盖比例更高者；相同取 V1。
- 若都不满足：关卡 1 用 V3，并在报告里写明"证据掩码不优于随机"。
- 若新增位点 < 100（在 A 上），D1 换成排序第二名，在 §9 记录。
- V3 无论如何都进入关卡 1，作为"无负约束"的参照（预期多报，M36 已见）。

### 4.3 评估（评估集 E，一次）

以新版注释为参考，项目 ruler（exact CDS chain，CDS ≥ 96 bp，不做后验过滤）：
1. 整体 exact-chain F1；
2. **缺失位点召回**：只在 E 上旧版缺失、新版新增的位点上，完整链召回；
3. 误检负担：预测中与新版任何基因都不重叠的链数；
4. 旧版"相同"基因上的完整链召回（是否破坏了原有正确注释）。

缺失位点按"有 / 无证据命中"分开报告。1 Mb 块配对 bootstrap（2,000 次，seed 0）给 U 对其余各臂的差。

### 4.4 继续 / 停止（单物种、单 seed，只作筛选信号）

**继续到关卡 2** 需要全部满足：
- U − Z > 0 且 U − L > 0（整体 F1 点估计）；
- U 的缺失位点召回高于 Z 和 L；
- U 的精度不比 Z 低 2 点以上。

否则停止：C2 在论文里写成"已知缺失位置时的部分观测"（上界设定），走路线 A。关卡 1 的结果无论如何都报告。

## 7. 关卡 0 结果（D1 枣，2026-11-24；本地 Mac，`m42_gate0.py`，提交 3cdadc5）

- **划分**：A = NC_029679 / 682 / 685 / 687 / 686 / 689（chr1、4、7、9、8、11），E = NC_029683 / 680 / 681 / 684 / 688 / 690（chr5、2、3、6、10、12）。
- **正例**：旧版 AR100 在 A 上 11,271 个蛋白编码基因，过滤后 10,472 个（剔除：剪接位点不合法 453、标为 partial 242、内部终止 83、跨缺口 21）。
- **证据**：miniprot 把 241,717 条跨物种蛋白比到 12 条染色体（M4，8 线程，约 40 min），A 上合格命中 104,312 条，合并成 8,403 段。
- **掩码冻结后**读 A 上的新版 AR101：11,483 个蛋白编码基因；新增位点 **753**，结构修订 1,734，相同 8,996；旧正例覆盖了 91.7% 的"相同"基因。新增位点中 310 个有证据命中，443 个没有。

| 掩码 | 新增位点 CDS 碱基落在未知区 | 新增位点完全落在未知区 | 未知区占 A 非正例碱基 |
|---|---|---|---|
| V1（证据 ±2 kb） | 50.2% | **32.8%（247 / 753）** | 24.4% |
| V2（证据 ±10 kb） | 72.4% | 57.1%（430） | 56.5% |
| V3（正例以外全未知） | 93.4% | 81.7%（615） | 100% |
| 随机（与 V1 同分布） | 18.9% | 11.2%（84） | 21.2% |
| 随机（与 V2 同分布） | 32.4% | 23.1%（174） | 40.1% |
| O 真值（上界） | 100% | 100%（753） | 1.7% |

- **§3.5 放行**：V1 通过（32.8% ≥ 2 × 11.2%，未知区 24.4% ≤ 30%）；V2 未知区 56.5% > 30%，不通过。**关卡 1 的 U 臂用 V1**，V3 作为无负约束参照（U3）。新增位点 753 ≥ 100，D1 不换。
- 需要一并说明的事实：
  - 随机掩码因区段重叠合并，覆盖率比 V1 低约 13%（21.2% 对 24.4%）；按覆盖率换算后 V1 仍约为随机的 2.5 倍。
  - V1 下仍有 67% 的新增位点至少部分落在背景里，即真实缺失基因多数仍被当作背景训练；这是证据掩码的现实上限，关卡 1 的 U 对 F 差值应按此解读。
  - V3 也只有 81.7% 的新增位点完全落在未知区：其余位点距离已有正例不到 1 kb，被正例两侧的保护区挡住。
  - 真值掩码 O 只需要 1.7% 的未知区就能覆盖全部新增位点；证据掩码要用 24% 才覆盖三分之一。

### 8.2 冒烟测试（2026-11-24，CAU；只用训练集 A 和 E 上 1 Mb，不打分）

- 环境：补齐 ont `~/envs/m32_extra` 里的同版本包（numba 0.62.1、pandas 2.3.1、scipy 1.15.3）后，U 和 L 各训练 8 步，均正常结束。
  - 每步：U 31–32 s，L 约 27 s（交叉熵几乎不耗 CPU）。首步含 Triton 编译，约 130–150 s。
  - 显存峰值 4.16 GB，与 ont 上的 M36 相同。
- 推理：NC_029690.1 前 1 Mb，46 s，约 57 kb/s（两条链）。
  - Z（T2）50 条链，U 8 步 57 条链；新版注释在这一段有 53 个蛋白编码基因（只数了个数，没有打分）。
  - **L 8 步后 0 条链**。参数相对 T2 的最大相对变化只有 3.9%（U 0.8%），排除程序错误。原因：逐位置交叉熵让每个碱基的"基因 / 背景"分数一起平移，CRF 解码时这个平移按基因长度累积，于是整条基因路径被压掉。训满 512 步只会更严重，§4.4 里的"U > L"因此成了必然结果。这一点在看到任何评估集结果之前发现，交给用户决定（决策卡 m42-L-arm）。
