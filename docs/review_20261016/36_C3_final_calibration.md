# 36 C3 终版校准分析：T2 基因级后验在独立面板上的可靠性与选择性注释（2026-11-24；计划写于计算之前）

依据：投稿前方案（`docs/presubmission_plan_20261123.md` §4.1）；用户 2026-11-24 决定走路线 A，并要求"继续做 C3"。本分析只用已有输出，在本地 Mac 的 CPU 上做，不占 ont。

## 1. 问题

终版 T2（PlantCAD2 + LoRA + 语法层，step 2304）给每条预测基因链一个后验 P(g) = exp(log_p)（τ = 1，M33 冻结的选择）。要回答三件事：
1. 这个后验在训练物种以外是否校准；
2. 按后验筛选能否换来可控的精度提升，即风险–覆盖率关系；
3. 与 Carbon-A 自带的置信分、与一个不需要后验的简单打分（解码增益 gain）相比，排序能力如何。

## 2. 数据（全部已存在；本分析不跑模型）

- **预测与后验**：ont `outputs/M34-NTV2-SCALEUP/panel/post_T2/<物种>/tau1/<contig>_<strand>.json`，核心 10 个面板物种的全部序列（P5 队列，2026-11-02 至 11-05）。每条链有外显子坐标、gain、log_p。
- **参考**：面板评分（报告 31）用的同一套标尺参考，即 `outputs/PANEL-P6/_refcache/ref_<contig>.pkl`（M26 CDS 可评估主转录本）。
- **Carbon-A**：原生 `carbonA/<物种>/<contig>/prediction.gff` 里基因行的 `confidence`。
- DEV 上没有 T2 后验（重算要 GPU），本次不做；DEV 的校准沿用已有的 M33（NT-v2）和 T10（set B）结果作背景。

## 3. 计数规则（与面板评分一致）

- 链：每个文件里的 genes；按 exact CDS 链去重，只保留 CDS ≥ 96 bp 的链（P2b / 面板规则）。
- 命中：链的 key 属于该序列的参考 key 集合。
- Carbon-A：未过滤的原生预测，每个基因取其主转录本链，规则同上；置信 NA 的基因单列计数，不进排序比较。

## 4. 指标（每个物种 + 10 种合并）

1. **校准**：
   - 10 个等宽箱的可靠性表（每箱：链数、平均预测概率、实际命中率）；
   - ECE（与 M33 相同的函数）和 Brier 分数；
   - 高置信箱（P ≥ 0.9）的实际命中率单独列出。
2. **排序**：以 log_p 为分数的 AUROC 与 AP，与 gain 为分数时的 AUROC / AP 对比。
3. **风险–覆盖率**：按 P 从高到低保留链，在覆盖率 100 / 90 / 80 / 70 / 50%（保留链数占比）处报告精度、召回、exact-chain F1；同时报告冻结阈值 log_p ≥ −1.400（M33 的 thr*）下的保留比例与 F1 变化。
4. **与 Carbon-A 在同覆盖率下比较**：两者各自按自己的分数保留同一比例（70% 与 50%）时的精度，并报告 Carbon-A 自身 conf ≥ 0.1 规则（"过滤版"）对应的覆盖率与精度。
5. **跨物种漂移**：每个物种的 ECE、高置信箱命中率，以及冻结阈值在各物种上的 F1 增益。

## 5. 不确定度

10 种合并后按 1 Mb 块（contig，链首个 CDS 起点 // 1 Mb）bootstrap，2,000 次，seed 0，给出：
- 合并 ECE 的 95% CI；
- AUROC(log_p) − AUROC(gain) 的 95% CI；
- 覆盖率 70% 时 T2 精度 − Carbon-A 精度的 95% CI（两者的块合在一起抽样）。

## 6. 解读规则（写在计算之前）

- 本分析是描述性的，不设成立 / 不成立判据。
- 论文里的 C3 只能写成"后验提供可用的排序与一定程度的校准"，并同时报告漂移最大的物种。
- 若合并 ECE > 0.10，或任何物种高置信箱的命中率比预测低 0.15 以上，必须在正文写明"跨物种校准不可靠"，不能只放在补充材料。
