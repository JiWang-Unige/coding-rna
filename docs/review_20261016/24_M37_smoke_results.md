## 4. 结果

### 4.1 错误独立性（主分析；A 参考 1,601 条，B 单独解码链投射到 A 坐标）

可投射参考（CDS 每个外显子边界都映射、链号一致、共线）1,226 条（76.6%）；B 的 1,355 条链中 1,115 条可投射到 A。

| | B 投射命中 | B 投射未命中 | 合计 |
|---|---:|---:|---:|
| A 单独命中 | 541 | 182 | 723（召回 59.0%） |
| A 单独漏检 | **52** | 451 | 503 |
| 合计 | 593（B 投射召回 48.4%） | 633 | 1,226 |

- **headroom = 52 / 503 = 10.3%**；并集召回 63.2%（A 单独 59.0%，上限只多 4.2 个点）。
- 独立性检验：若两侧错误独立，A 漏检 503 条中应有 503 × 48.4% ≈ 243 条被 B 命中，实际 52 条（0.21 倍）；优势比 25.8，φ = 0.63。**错误高度共享**。
- 分层（1 段 / 2–5 段 / ≥6 段）：headroom 8.9% / 10.9% / 10.3%；优势比 31.3 / 30.2 / 18.2。多外显子基因错误共享程度略低，但 headroom 仍只有一成。
- 只计 CDS 全部碱基可映射的 972 条参考：both 486 / A-only 108 / B-only 50 / neither 328，headroom 13.2%。
- 反方向（B 参考 2,159 条，1,592 条可投射，A 链投射到 B）：both 474 / A-only 84 / B-only 36 / neither 998；B 漏检中 A 投射命中 84 / 1,082 = 7.8%，A 漏检中 B 命中 36 / 1,034 = 3.5%；优势比 156，φ = 0.83。B 侧 "neither" 占 63%，反映 B 的 GLEAN 注释与草图装配质量（B 单独解码对 B 注释 F1 仅 37.6，而同一模型在 A 上 57.6），B 方向数字只作描述。

### 4.2 势平均联合解码（A；pot_A′ = (1−λ)·pot_A + λ·proj(pot_B)，仅可映射的 15,054,840 个碱基；skyline 整 contig 解码）

| 臂 | 链数 | TP | 精确率 | 召回 | exact-chain F1 [95% CI] | Δ vs A 单独 [95% CI]（frac>0） | 1 段 / 2–5 段 / ≥6 段 | CDS 碱基 P / R / F1 | 背景 kb（%） |
|---|---:|---:|---:|---:|---|---|---|---|---|
| A 单独（M33） | 1,401 | 865 | 61.74 | 54.03 | 57.63 [52.66, 61.31] | — | 73.06 / 53.86 / 47.47 | 92.71 / 80.30 / 86.06 | 66.7（0.410） |
| λ=0 | 1,401 | 865 | 61.74 | 54.03 | 57.63 | 0.00 [0.00, 0.00]（链集合逐条相同） | 同上 | 同上 | 同上 |
| λ=0.25 | 1,391 | 885 | 63.62 | 55.28 | 59.16 [53.96, 63.03] | **+1.53 [+0.76, +2.17]**（1.000） | 73.59 / 55.36 / 50.00 | 92.84 / 80.13 / 86.02 | 65.1（0.400） |
| λ=0.5 | 1,370 | 892 | 65.11 | 55.72 | 60.05 [54.85, 64.04] | **+2.42 [+1.14, +3.58]**（1.000） | 73.98 / 56.59 / 50.97 | 93.25 / 79.69 / 85.94 | 62.3（0.383） |

bootstrap：1 Mb 块（24 块）配对自助 2,000 次、seed 0，与 M31 `c1_boot` / M33 `m33_dev` 同法；块数少（单条 24 Mb 染色体），区间较宽，但两档 λ 的配对差区间都不含 0。约 86% 的预测链落在可映射碱基内（三臂相同），增益不是来自不可映射区。

### 4.3 描述性：哪些参考变了，局部分歧如何

λ=0.5 相对 A 单独：**miss→hit 53 条**（1 段 6 / 2–5 段 22 / ≥6 段 25；其中 50 条可映射，**32 条是 B 投射命中的基因，21 条 B 自己也没解对**），**hit→miss 26 条**（其中只有 1 条 B 投射命中）；假链新增 116、移除 174（新增假链 95% 在可映射区）。λ=0.25：miss→hit 30（18 条 B 命中）、hit→miss 10（0 条 B 命中）；假链 +67 / −97。

参考基因区的 A–B 分歧（映射统计）：错配中位 3.1 / kb，indel 中位 0.73 / kb，参考区平均 13.7% 碱基不可映射。各类转移之间的分歧密度差别小（错配 3.0–4.2 / kb）；miss→miss 类的不可映射比例最高（19–20%），hit→hit 10%，miss→hit 和 hit→miss 几乎全可映射（0–1.6%）——联合解码只在完全可映射的基因上改变结果，而仍漏的基因里有相当一部分本来就缺少 B 侧证据。

解读：52 条 "B-only" 基因只有一部分被势平均救回（λ=0.5 时 32 条），另外 21 条救回的基因 B 自己也解错，说明增益机制是**两份带噪声势的平均降低了连接处的局部噪声**（集成效应），而非协议 §0 设想的"B 把 A 漏掉的基因解对"。精确率涨幅（+3.4）大于召回（+1.7），假链净减 58 条，与"平均抑制偶然的假连接"一致。

## 5. 判据判定（协议 §5）

| 协议判据 | 本次结果 | 满足？ |
|---|---|---|
| headroom ≥ 20% | 10.3%（分层 8.9–10.9%；全碱基可映射子集 13.2%） | **否** |
| λ 任一取值下 ΔF1(A) ≥ +1.0 且配对 CI 下界 > 0 | λ=0.25 +1.53 [+0.76, +2.17]；λ=0.5 +2.42 [+1.14, +3.58] | 是 |

按协议 §5 的表（判据写于任何结果之前，不事后修改）：headroom < 20% → **NO-GO**：错误在单倍型间共享，联合解码没有"互补纠错"的空间；多装配联合解码方向不立项，泛基因组应用只保留"一致性 / PAV 不确定性"。

需要如实记录的张力：§5 的表没有预设"headroom < 20% 但 ΔF1 ≥ +1.0 且显著"这一格。本次正是这种情况：前提（错误独立）被证伪，但势平均带来的 +2.4 F1 比 M33 的后验过滤（+1.7）还大，且碱基级 F1 不降、背景负担下降。它说明可取的不是"多装配互补纠错"，而是"同一基因的多份独立观测做势级集成"。这与 NO-GO 的判定并不冲突——被否定的是协议 §0 的机制假设和由它推出的泛基因组应用叙事。若用户想把"势级集成"作为新方向，需要另写预注册协议（至少换第二个物种对、用高质量装配 B、加入非平凡的合并方式对照，并解释为何不是简单的 test-time augmentation），本报告不替它立项。

局限（影响判定的强度）：单物种、单染色体、单模型；B 是 2011 年草图装配 + GLEAN 注释（B 侧参考弱，B 方向结果不可用于判定）；24 个 1 Mb 块的 bootstrap；A 可映射碱基 62.9%，不可映射区天然无增益；λ 只试了两档且无按后验加权等替代合并方式。

## 6. 偏离与局限

协议 §8 记录的偏离，按时间：

1. **装配 B 的选择（22:47，执行前）**：MH63RS3、ZS97RS3、R498 及 2020 年的两个 9311 装配在 NCBI 均无注释；按优先序取第一个带注释的染色体级装配 **9311 ASM465v1（GCA_000004655.2）chr10 = CM000135.2**。未退到 IRGSP-1.0。代价：草图装配（2.85% N）、2008 年 GLEAN 注释，B 侧评分只作参考。
2. **identity 的口径（23:06，映射建好、§4 无任何结果前）**：协议未定义"identity ≥ 90%"；PAF 的 matches/块长把 gap 碱基全部计入分母，indica–japonica 长链只有 0.75–0.90，按此只剩 4.54 Mb（A 的 18.6%）；改用 minimap2 标准的 gap-compressed 口径 **1−de ≥ 0.90**（中位 0.984），得 662 块、A 62.9% 可映射。两种口径的统计都在 `align/map.json`，旧口径映射另存 `map_rawratio_superseded.*`，未对其做联合解码。
3. **解码核 25–31 而非 24–31（22:55）**：M35 训练进程的 affinity 含核 24，让出。
4. **窗口级缓存续跑（23:17，B 无任何势、§4 无任何结果前）**：共享 GPU 下一条链编码 ≈ 19 分钟 + 模型加载，20 分钟看门狗两次切断且按链续跑无效。不放宽 20 分钟上限、不改冻结代码，只在 `m37_infer.py` 加每批 4 窗的 FP32 势缓存（`inferB/cache/`，写出势后删除），重启回放；拼接器收到的记录序列与一次跑完完全相同。驱动续跑次数 3 → 12。核对 M35 步时未受影响。
