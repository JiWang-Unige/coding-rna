## 2. 新主张（按论文结构，均为待检验）

- **C1 性能**：GLM 编码 + 完整基因集似然训练 + 精确语法解码，在 ≥12 个独立植物基因组（时间留出 + 同源审计）上的完整 CDS 链 F1 超过 Helixer、Tiberius、ANNEVO，并 ≥ Carbon-A。判据：面板中位数与配对检验，3 seeds，bootstrap CI。
- **C2 部分监督适配**：由于未知位置被边缘化，模型能利用不完整注释（仅高置信/BUSCO/蛋白同源支持的基因，或 k% 随机基因）在新物种上适配；在同等标签量下优于"未知填背景"训练，并以远少于完整注释的标签接近完整标签性能。
- **C3 校准的基因级后验**：配分函数给出的基因后验在各物种上校准良好（可靠性曲线/ECE），可直接用于精度-召回控制与注释质控，优于或不需要单独的置信网络（对标 Carbon-A 置信网络）。
- **C4 机制**：GLM 注释器的主要错误来自多外显子结构之间的评分竞争，而非语法容量不足；该结论在独立面板上复现，并指导了 C1 的改进。

C1 不成立时，论文以 C2+C3+C4 为主体投 NC；C1 成立时，以 C1 为主体、C2/C3 为差异化能力，冲击 Nature Methods。

## 3. 两条并行工作线

**性能线（C1）**：依据 06（Carbon-A 差距分析）确定的差距来源排序，先做只读重放/无 GPU 诊断，再做小规模 ont 训练。候选：编码器结构化微调（更大 LoRA/更多层）、扩大训练物种（部分标签可直接使用不完整注释，与 C2 相互支撑）、多段基因的长上下文处理、基于后验的过滤、换基模或集成。

**主张线（C2–C4）**：
1. 独立植物面板构建（核对各工具训练物种清单，选时间留出 assembly，同源审计）。
2. marginalize vs background vs fine-only 对照（同训练预算，3 seeds）。
3. 部分标签比例曲线（k ∈ {5, 10, 25, 50, 100}%，以及 BUSCO-only、蛋白支持-only）。
4. 后验校准分析与基于后验的阈值曲线。
5. 全部工具在面板上同口径运行（我方、Carbon-A、Tiberius 植物模型、Helixer、ANNEVO，可选 BRAKER3 ab initio），BUSCO、运行时间。
