## 3. 判定（协议 22 §5，读法见 §9 10-26 17:32 条）

- **GO-强：不成立**（S2、S3 在两物种都比 Carbon-A 过滤低 7.4–12.5 点）。
- **GO：不成立**（S1、S3 在两物种的闭合比例均为负）。
- **NO-GO：成立**——两物种中 S1 / S2 / S3 没有任何一臂达到 30% 闭合；最好的一臂（S3）闭合 −26% / −63%，即适配后比零样本更差。
- 主统计量（基因单位）与 1 Mb 块判定一致，`verdict_statistic_sensitive = false`。
- **C2 撤回条款触发**：F1 − S1 = −0.94 ≥ −2.0 点。按 §5 最后一行，"边缘化优于填背景"的机制主张在本设置（伪标签 / 证据种子适配）下撤回，只保留 M30 的结果（参考标签部分观测，Carbon-A 骨干）。注意 CI 整体 < 0，即填背景在统计上确实更差，只是差距小于预注册的 2 点门槛。

**按协议的后果**：自举 / 证据种子适配方向放弃，论文按 `paper_outline_20261027.md` §6.4 止损。§6.4 现分两支，取决于 C1 独立面板判据（12-01 后在 Baobab 上跑面板基线，结果未出）：面板达成 → 以 C1 + C2 + C3 + 骨干分解为主体投 Nature Communications；面板未达成 → 框架篇投 Genome Biology / NAR Genomics & Bioinformatics。"M36 GO 但面板未达成"的待定组合不再相关。
