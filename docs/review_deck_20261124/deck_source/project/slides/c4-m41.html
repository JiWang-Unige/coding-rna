Why M41 was run (protocol 33, registered 11 November). The panel had shown that T2 falls behind on long, many-exon genes. If the grammar's single intron state could not represent both short and very long introns, splitting it into a short-intron and a long-intron state (with their own length behaviour) might help many-exon genes. This was the one grammar-side change we tried for C4. Criterion (verbatim in protocol 33): the main endpoint is d(≥ 6), the difference in DEV exact-chain F1 on genes with six or more CDS segments between M41 and T2, with the threshold at twice T2's seed standard deviation (2.58 points). Results (21–22 November, protocol 33 §9). DEV 73.26 overall, 70.95 on ≥ 6-segment genes. Against T2: d(≥ 6) −0.74 [−1.71, +0.23]; overall −0.62 [−1.19, −0.03]. Set B: 65.06, 3.41 below T2 [−3.78, −3.05], with 24,590 predicted chains against 21,875 references (12% over-calling). Verdict: no detectable effect. What it tells us. The multi-exon and long-gene gap is not fixed by a richer intron length model in the grammar. Together with the long-gene stratification (previous slide), this points to the potentials (backbone features and training geometry) rather than the grammar's capacity, which is what the older C4 replay suggested too. The cost was about one training run on ont; a 17-hour delay came from the TE-gate bug. Not tried. Training with longer windows so that long genes are seen complete; a decoder that uses evidence across windows. Either would be a new experiment (GPU) and is listed on the questions slide.
