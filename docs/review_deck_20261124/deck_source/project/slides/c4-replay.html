Left panel: where each reference gene of set B ends up (Dryas and Eschscholzia pooled, weighted by genes; raw file experiments/M33-NTV2-FOLLOWUP/results/diag_failure_modes.json). Three outcomes: an exact predicted chain; a predicted chain that overlaps but differs in at least one segment; no overlapping prediction. - One segment (4,145 genes): Carbon-A 68% exact; NT-v2 + LoRA 65%. Misses dominate the errors for both (27–28%). - 2–5 segments (9,667): Carbon-A 69% exact, 11% overlapping; NT-v2 47% exact, 26% overlapping. - ≥6 segments (8,063): Carbon-A 73% exact, 16% overlapping, 10% missed; NT-v2 35% exact, 58% overlapping, about 7% missed. So for multi-exon genes NT-v2 finds the gene (it overlaps something) but joins the exons wrongly. Report 18 states the overall share of “overlapping but not exact” as 33.6% and 35.0% for NT-v2, against 11–13% for Carbon-A. Right panel: the matched final-update score replay of an M28 GENERanno model with joint encoding (24,576-bp windows, DEV 66.62; not the final fresh-joint model of 16 October, DEV 70.11) on TRAIN (report 04; experiments/M28/full_grammar/reports/full_grammar_matched_energy_diagnostic.md). Of 7,762 reference genes it missed, 5,067 (65%) could be represented by the grammar and scored above background but lost to an overlapping competitor in the decoded set; 2,486 (32%) scored below background; 209 (3%) were not allowed by the grammar. That is why C4 says “scoring competition, not grammar capacity”: the grammar almost never excludes the right answer. Limits. Both panels come from backbones we no longer use as the final model: NT-v2 on set B and GENERanno on TRAIN (training data, so in-sample). The same breakdown for T2 has not been made. It compares predictions with references (M33’s diagnostic script), and T2 was run on set B for P2b, so it should be a CPU job if those predictions are still on ont (not checked here). The replay also needs the model’s energies; for T2 these would have to be recomputed, or taken from the panel inference while its potentials are still kept. Why it matters for the paper.
