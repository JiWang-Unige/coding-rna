Seeds. Most models in the deck were trained once; T2 three times, the P4 arms twice. For T2 the head initialisation seed is 0 and the sampling seed is 1; T2_s2 and T2_s3 change the sampling order and the LoRA A-matrix initialisation. They give seed spread for T2 on DEV, the new-species regions and set B; the panel seed runs (triggered by the rule of 7 November) have not run yet. Every CI in the deck therefore measures resampling of genes or regions, not training variance. Two bootstrap schemes. DEV: paired bootstrap over 54 blocks of 1 Mb (contig, first CDS start divided by 1 Mb), 2,000 draws, random generator seed 0 (c1_boot.py). Set B in M30, M33 and M36: reference genes plus 100-kb bins for orphan predictions are the resampling units (m30_score.py). P2b on set B used 1-Mb blocks instead. The schemes give different widths for the same comparison; the deck labels which one each number uses, and set B CIs of T2/T10 should not be compared directly with those of Carbon-A or NT-v2. Checkpoint selection. All M34 arms take the best pooled score on the Arabidopsis + rice internal-validation chromosomes (NC_003071.7, NC_089044.1) among steps 1,536, 2,304 and 3,072, ties to the later step (m34_select.py). It never looks at new species, DEV or set B. Side effect seen in P4: the margin depends on which checkpoint each arm happens to get. Posterior temperature and threshold. Chosen once in M33 on the NT-v2 model’s internal validation (minimum ECE gives τ = 1; threshold log P ≥ −1.400), then reused unchanged for T10 in M36 and for the panel posterior queue. Clean, because no test data chose them; but not tuned for PlantCAD2. Criteria. Git proves “registered before the result” for M34 P1–P4 (plan 19), P2b (24 October, before T10 output), M36 (protocol 22, with three ambiguities settled on 26 October before any output), M37 (protocol 23 committed at 22:54 on 21 October, one minute before its first GPU session) and the C1 panel rule (27 October, before any panel output). The criteria of M29–M33 first entered git in a batch commit on 21 October, after their results; for those, the order rests on the reports’ own time stamps. Further caveats: θ = 6.0 was chosen after set B; M36’s criteria were written after the Carbon-A and NT-v2 set B results were known. No criterion was changed after its result. Two undocumented deviations from plan 19, found in this review. (1) Plan 19 set an advance rule: if Dioscorea’s T10 internal-validation F1 fell more than 15 points below the median of the other new species, replace it with Ananas comosus and rerun. It fell 18.6 points below (53.46 against 72.09); nothing records a decision, and Dioscorea stayed in T10, k50U and k50F. P4 is not at risk (Dioscorea was the smallest margin, +0.20), but the deviation should be written down. (2) The plan’s seed rule asked for two more T10 seeds once P1 passed; the queue has two T2 seeds instead, which is sensible since T2 is the final model, but no revision entry says so. Short chains. The scorer drops predicted chains with less than 96 bp of CDS for our arms only; the Helixer, Tiberius and ANNEVO rows on DEV were never rescored with that rule. On our models the rule moved F1 by 0 to +0.23 points; on the tools the effect is unknown. Harmless for most comparisons; the panel scoring (report 31) applied it to every tool. Paired CIs exist only against Carbon-A and GENERanno on DEV; there are none against Tiberius, Helixer or ANNEVO, and on set B T2 and T10 have only point differences to Carbon-A. Multiplicity. Many comparisons are reported with 95% CIs and no correction. The decisions rest on a few pre-registered primary contrasts; the rest is description and should be worded so.
