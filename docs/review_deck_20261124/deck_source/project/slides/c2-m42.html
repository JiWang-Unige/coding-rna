(1) 512 steps of adaptation with the old annotation lowered F1 in all three trained arms (−1.6 to −4.5), as in M36. (2) The only detectable advantage of marginalising over filling is on missing loci (+2.2). (3) Without negatives (U3) the model finds more missing loci (19.7%, even 18.2% without evidence) at the cost of 21% more predictions. (4) Every model is far below simply keeping the old annotation (74.68): in practice a model could only add new loci. Consequence (protocol 35 §4.4).
