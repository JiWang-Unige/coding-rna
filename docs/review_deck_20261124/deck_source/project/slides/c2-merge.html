Why this analysis (your decision "路线A加合并分析", 24 November). If the model cannot replace an old annotation, can it at least add the genes the old annotation missed, without harming the genes it already has right? The rules were written and committed (e2478e9) before running. Rules. Keep every old CDS chain on E. Add a model chain if no CDS base overlaps any old CDS on either strand (G0, "anywhere in the gaps"), or additionally only if its CDS span lies entirely inside the E evidence region, i.e. protein hits ±2 kb (G1, "inside evidence regions"; 64.6 Mb, 43% of E). Same ruler and bootstrap as gate 1. Results. Every merged set keeps 98.0% of the old-identical genes. Missing-locus recall rises to 6.8–19.7%, but the added chains are mostly wrong (5.3–14.9% hit a new-release chain exactly), so F1 drops 0.7 to 6.9 points below the old annotation. The pre-written "practical value" condition (F1 not lower and missing-locus recall higher) is not met. Paired differences (1-Mb blocks): old + U (G1) − old: F1 −1.11 [−1.29, −0.92], missing loci +8.44 [+5.99, +10.90]. old + U (G1) − old + Z (G1): −0.19 [−0.29, −0.08] and −1.04 [−2.00, −0.15]. old + U (G1) − old + F (G1): −0.44 and +1.63 [+0.78, +2.59]. old + U (G0) − old: −2.94 and +15.70. old + Z (G1) − old: −0.92 and +9.48. Reading. The evidence gate halves the additions and slightly raises their precision, but what it finds is almost only evidence-supported loci (0.7–2.2% of the evidence-free ones). U is again no better than the zero-shot model; it only beats F on missing loci (+1.63), consistent with gate 1. For the paper: an honest upper limit on recovering missed genes, and a stated limitation that model calls in annotation gaps are of low precision.
