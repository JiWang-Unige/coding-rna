Design (protocol 35, committed before any data were downloaded). Species chosen from NCBI metadata only: same assembly accession with an older and a newer RefSeq annotation release, chromosome level, not in PlantCAD2's pretraining, enough newly added genes. First choice Ziziphus jujuba (Rosales; AR100 March 2016 → AR101 May 2018; 438 Mb); confirmation species Solanum pennellii; an insect added for gate 2 by your decision. Split. Twelve chromosomes ranked by length; odd ranks train (A), even ranks evaluate (E). Positives. Old-release representative transcripts on A that are complete and valid (start/stop, frame, canonical splice sites, no gaps): 10,472 of 11,271 genes. Evidence. miniprot alignments of the same ten species' proteins used in M36 (not jujube's own): hits with ≥ 50% coverage and ≥ 40% identity. Masks frozen before the new release was opened: V1 = evidence spans ±2 kb; V2 = ±10 kb; V3 = every non-positive base. Positives ±1 kb are never unknown. Gate 0 audit (A only, new release read after freezing). 753 genes are new in AR101 (no CDS overlap with AR100); 1,734 revised; 8,996 identical; positives cover 91.7% of identical genes. Missing loci fully inside the unknown region: V1 32.8% (random mask of V1's size 11.2%), V2 57.1% but 56.5% of non-positive bases unknown (rule ≤ 30%: fails), V3 81.7%, oracle 100% with only 1.7% unknown. Rule: V1 passes (≥ 2× random, ≤ 30% unknown) and goes to gate 1; V3 runs as the no-negative-constraint reference. Gate 1 arms. Z = T2 zero-shot. U = positives + V1 unknown + rest background. F = positives + everything else background. U3 = positives + V3. L (per-position cross-entropy) was dropped after it collapsed in the smoke test, before any scoring (your decision). Continue rule after that revision: U − Z > 0 and U − F > 0 in F1, U's missing-locus recall above Z's, and U's precision not more than 2 points below Z's. Compute.
