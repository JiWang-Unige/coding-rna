## 1. 结论

- **现在的结果能串成一个连贯的故事，但还不够有说服力地投 Nature 子刊。**
  - 故事：参考注释不完整时，把"未注释"当"非基因"会伤害模型；对完整基因结构做概率建模、把未知位置边缘化，可以避免这种伤害，同时给出基因级后验。
  - 不够的原因不是缺表格，而是缺一项能证明这个优势在**真实**不完整注释上仍然成立的决定性证据。
- **两个关键批评（都已核实）：**
  1. **掩码借了完整真值。** C2 的 U 臂是用完整注释定位被删基因、再把那些位置标成未知（报告 19 §3.10，我们自己写了"上界设定"）。真实场景里不知道漏在哪。昆虫 M39 同样如此（协议 29 §4.5）。
  2. **部分标签几乎没有净增益。** 完全不用 8 个新物种标签的 T2 在这些物种上是 68.84（报告 20 §14），k50U 两个 seed 是 67.86 / 69.03，全标签 T10 是 69.62。所以现在能说的是"边缘化避免了填背景的损失（k50F 64.62 / 54.06）"，还不能说"部分标签让模型变好"。M30 同样：U 对未适配闸门 −0.32 / −0.79。
- **还要注意的已有工作（2026-11-23 已核实）：**
  - 部分标注 CRF 的边缘化训练：Tsuboi, Kashima, Mori, Oda, Matsumoto. *Training Conditional Random Fields Using Incomplete Annotations*. COLING 2008, pp. 897–904（ACL Anthology C08-1113；doi:10.3115/1599081.1599194）。对与不完整标注一致的所有标签序列求和，用于日语分词与词性标注——与我们的 U 是同一个目标函数。
  - CRF 做基因预测：Vinson 等，*Comparative Gene Prediction using Conditional Random Fields*，NIPS 2006；DeCaprio 等，*Conrad: gene prediction using conditional random fields*，Genome Res 2007;17:1389–98（doi:10.1101/gr.6558107，半马尔可夫 CRF）；Bernal 等，*Global discriminative learning for higher-accuracy computational gene prediction*（CRAIG），PLoS Comput Biol 2007;3:e54（doi:10.1371/journal.pcbi.0030054）。
  - DNA 基础模型 + CRF 做植物基因注释：Liu 等，*GeneCAD: Plant Genome Annotation with a DNA Foundation Model*，bioRxiv 2025（doi:10.1101/2025.10.31.685877；PlantCAD2 表示 + ModernBERT + 染色体级 CRF；五个留出被子植物上 transcript F1 比 Helixer、BRAKER3 高 8–10%）。
  - 一次扩展检索没有找到在基因预测里对未注释区域做边缘化训练的工作；最接近的是 PU 学习（病理图像细胞检测）与自训练基因预测（GeneMark-ES）。这只说明没搜到，不等于不存在，写"首次"前要再查。
  - 结论：CRF 做基因结构、部分标注 CRF 都不是新的，GeneCAD 已是 PlantCAD2 + CRF。新颖性只能落在"完整基因语法上的部分观测训练，用于真实的不完整基因组注释"这一组合带来的新能力上；GeneCAD 基线因此更重要。

## 3. "不借真值的 C2"（路线 B）设计要点

- **真实的不完整注释来源：** 同一装配（accession.version 相同）的旧版与新版 RefSeq 注释。旧版作为已知正例，新版作为评估参考。
  - 只把"新版新增的独立基因位点"算作缺失基因；结构修订单独报告；装配或 ID 变化造成的假新增要剔除。
  - 旧版里与新版冲突的基因模型先不进主判据（避免把"标签错误"和"标签缺失"混在一起；M36 的教训是种子链约四分之一错误时边缘化救不回来）。
- **三态监督，而不是"有证据 = 未知，其余 = 背景"：**
  - 正例：旧版可信、结构完整的 CDS；
  - 未知：其余未确认区域（有 RNA-seq / 蛋白信号的区域另作标记）；
  - 可信负例：只来自事先定义的保守规则，不能用"没有证据"当负例，更不能用"与新版基因不重叠"（那就又借了真值）。
  - 证据区域要预先定义向外扩展的规则，避免真实外显子落在未知区外被当成背景。
- **防泄漏：** 先冻结证据处理规则和掩码，再打开新版注释；证据最好限定在旧版发布时已存在的数据。
- **对照（同一初始化、同一调度、同一可见信息，只换训练目标）：**
  - Z：不在目标物种上训练（零标签）；
  - F：旧版未注释处填背景；
  - L：逐位置交叉熵，只在可信位置算损失，用同一个 CRF 解码器；
  - H：结构化硬补全（只取与观测一致的最优一条路径来训练），用来区分"结构化训练的价值"和"对所有补全求和的价值"；
  - U：部分观测配分函数（我们的方法）；
  - nnPU 放到第二批（标准 PU 的随机缺失假设在旧版注释上不成立）。
- **终点：** 整体 exact-chain F1；只在旧版缺失、新版新增位点上的完整链召回；误检负担。并把缺失基因按"有 / 无证据支持"分开报告。
- **场景：** 第一轮用 PlantCAD2（T2 初始化）+ 一个预先定义的远缘植物目标物种（按系统发育距离、同装配新旧版本、新增基因数量、公开证据等标准选，不按我们看过的 F1 挑）；面板里的 Hakea / Akebia / Amborella 只能用于开发，确认要换另一个没用于设计的物种。第二轮在昆虫上确认，需要补一个只用果蝇 + 赤拟谷盗训练的 I2 源模型（约 20–36 GPU h）作为昆虫零标签基线。
- **三道关卡：**
  - **关卡 0（0 GPU h）：** 找一对合格的新旧注释，按冻结规则生成掩码，再做一次掩码审计（新增基因被未知区覆盖的比例、未知区占全基因组的比例、旧基因保留率，并与同覆盖率的随机掩码比）。若覆盖新增基因需要把几乎全部非注释区设为未知，就先不训练，问题出在证据选择上。
  - **关卡 1（约 12–25 GPU h；四臂约 25–40）：** 512 步 LoRA 小试，先跑 U 与 L，加上 Z。继续的条件：U 同时优于 Z 和 L，缺失基因召回上升，精度不崩。只作继续 / 停止的信号。
  - **关卡 2（PlantCAD2 四臂约 140–220 GPU h）：** 正式 3,072 步，四臂。12-01 后可部分转 Baobab（提交前问用户）。

## 4. 不论哪条路线都该做的（不占 GPU 或很少）

1. **C3 终版分析**（CPU，数小时到一天）：终版 T2 在 DEV 与独立面板上的可靠性曲线、ECE / Brier、风险—覆盖率曲线；与 Carbon-A 置信分、简单的打分基线在同一覆盖率下比较。已有数据显示跨物种校准有漂移（Esch 高置信箱预测约 0.94、实际约 0.74），要如实报告。
2. **P4 训练动态分解**（CPU，几小时）：各停点的 U − F、预测数、召回，两个 seed 并列；说明 +9.10 主要来自 k50F_s2 的少报，不当作稳定的效应量。
3. **长基因失败分层**（CPU，1–3 天）：面板上困难物种的错误类型，先分析再考虑新模型。
4. **GeneCAD 基线**（12-01 后 Baobab，提交前问用户）。
5. **写法修正（现在就能定）：**
   - C2 写成"缓解把未知当背景造成的损失"，不写"少量标签超过全标签"；
   - 注释量曲线只作描述（三个点、各自选点、单 seed），不写成 scaling law；
   - 骨干比较写成"预训练表示的选择显著影响完整基因结构重建"，不写成"植物预训练学到了更普适的语法"（DEV 物种在 PlantCAD2 预训练里，且架构、数据、分词同时不同）；
   - 面板上 T2 与 Tiberius、Vipsania 逐物种是 5:5、6:4，Holm 校正后不显著，只有与 Carbon-A 的落后方向一致且明确；
   - 代码与复现材料需要整理成可运行的管线（报告 01 §5 列过硬编码路径等问题）。
