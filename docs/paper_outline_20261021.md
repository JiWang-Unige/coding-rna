## 0. 定位：一句话故事

**"一个与骨干无关的概率化基因语法层：把任意 DNA 语言模型变成可用不完整注释训练、输出校准基因后验的完整基因注释器。"**

为什么不是"新 SOTA 工具"：

| 事实 | 出处 |
|---|---|
| 同主权重的 Carbon-A（2026-10-08 发布）在 DEV 过滤后 77.41，我方最佳 GENERanno 配方 70.11；在冻结 Carbon-A 特征上学残差/适配头没有增益（M29-A1/A2、M30） | 07 §5–6、§9 |
| ANNEVO（MoE + Viterbi，566 物种）、Tiberius（可微 HMM，多谱系）、GeneCAD（PlantCAD2 + CRF）、PlantGeneAnn（Mamba-MoE）已占据"GLM/深度表示 + 语法解码"和 MoE 两个点 | 05 §3.1 |
| 单 4090 共享 + Baobab 12-01 前冻结，不可能复制 ANNEVO/Carbon-A 的训练规模 | 00 §3 |

与 Carbon-A/ANNEVO/Tiberius 真正不同、且已有证据的三件事：

1. **未知位置边缘化**（配分函数 CRF 的"部分观测似然"）：填背景会让召回崩溃（M30：U − F = +16.5 / +14.2 点，两物种同向）。这是 Carbon-A/ANNEVO/Helixer 训练目标做不到的。
2. **自带校准的基因后验**：配分函数训练的模型 τ=1 即校准（M33：ECE 0.031，AUROC 0.82），不需要 Carbon-A 那样单独的置信网络（ECE 0.067）；过滤在同物种 +1.7、新物种 +2.3–2.5 点。
3. **骨干无关**：同一头、同一语法、同一数据下已跑通 NT-v2（纯自监督）、PlantCAD2、GENERanno/Carbon-A 三种骨干，并给出受控的骨干贡献分解（05 §3.2 第 2 条列为文献空白）。

论文主线因此是 **"框架能力 + 多骨干一致收益 + 注释效率"**，而不是"零样本精度第一"。精度表仍要做（审稿人必问），但主张写成"在每个发射源上都一致提升，并在独立面板上达到/接近最强工具"。

档次判断（07 §2 规则）：C1 多物种放大后若在独立面板上 ≥ Tiberius 且接近 Carbon-A，冲 Nature Methods；否则以 C2+C3+骨干分解为主体投 Nature Communications。两种情况的大纲相同，差别只在摘要第一句和 Fig. 4 的措辞。

## 2. 论文大纲

### 题目（候选）

1. *A backbone-agnostic probabilistic gene grammar turns DNA language models into calibrated, annotation-efficient gene annotators*
2. *Learning complete gene structures from incomplete annotations with DNA language models*
3. *Calibrated ab initio gene annotation from partial supervision across DNA foundation models*

若 C1 在独立面板成立且 ≥ Tiberius：用 1；若以 C2/C3 为主体：用 2。

### 摘要骨架（约 150 词，Nature 系无结构摘要）

1. 问题：真核基因注释的深度方法（Helixer、Tiberius、ANNEVO、Carbon-A）都需要大规模完整注释训练，输出单一最长转录本，没有校准的基因级不确定性。
2. 方法：提出 **[软件名，暂 cdsgram]**：完整 CDS 语法下的全集合配分函数 CRF，精细标签硬约束、未知位置边缘化；整条 contig 精确解码；后验直接可用。
3. 结果 1（骨干无关）：在 NT-v2、PlantCAD2、GENERanno 上一致 **[待填：各骨干 F1 与 LoRA 增益]**。
4. 结果 2（注释效率）：用 **[待填 k]%** 的基因注释即达到完整注释 **[待填]%** 的性能；填背景训练召回崩溃 **[M30 已有 +16.5 / +14.2]**。
5. 结果 3（校准）：后验 ECE **[M33 已有 0.031]**，跨 **[待填 N]** 个物种稳定，选择性注释在同召回下精度高于 **[待填]**。
6. 结果 4（基准）：在 **[待填：12 或 10]** 个时间留出植物基因组上 **[待填：≥ Helixer/Tiberius，与 ANNEVO/Carbon-A 的差距]**。
7. 应用一句：**[待填：isoform 或泛基因组]**。
8. 可用性：单 GPU 训练 **[待填 h]**、推理 **[M33 已有 162–207 kbp/s]**，Apache/MIT 开源。

### Introduction（≤ 4 段，参照 ANNEVO 的写法）

1. 注释是基因组学的瓶颈；证据驱动流程（BRAKER3）依赖 RNA-seq/蛋白；ab initio 深度方法崛起（Helixer NM 2025、Tiberius、ANNEVO NM 2026、Carbon-A 2026、GeneCAD、PlantGeneAnn）。
2. 共同局限（**这是论文的立足点，每条都要有引文**）：
   - 训练需要完整参考注释，未注释位置被当作背景 → 不能用 BUSCO/蛋白同源/部分 Iso-Seq 这类**不完整证据**训练；
   - 没有有理论依据的基因级后验（Carbon-A 用单独置信网络；Tiberius/Helixer/ANNEVO 无）；
   - 单一最长转录本输出、评估也只对最长转录本；
   - 各工具绑定各自骨干，GLM 预训练、规模、解码器的贡献无法受控比较。
3. 本文贡献（四条，对应 C1–C4/C5）。
4. 一句话结果预告 + 开源。

### Discussion（要点）

1. 框架层价值与"骨干会变"：今后更强的开放骨干可直接接入（已用三种骨干证明）。
2. 不完整证据训练的实际意义：BUSCO/蛋白同源/少量 Iso-Seq 即可训练；与 BRAKER 式证据驱动的衔接。
3. 校准后验的用途：注释质控、选择性下游分析、泛基因组比较。
4. 局限（必须写）：零样本跨物种差距 **[待填 M34 后]**；多外显子连接仍是主要误差；仅 CDS（无 UTR、无 ncRNA）；仅最长/主转录本评估的局限；训练面板偏 RefSeq/Gnomon 标签风格；骨干预训练暴露（PlantCAD2 预训练窗口取自注释基因 ±5 kb；GENERanno/Carbon-A 快照含拟南芥/水稻）。
5. 展望：UTR/ncRNA 语法扩展、泛基因组图注释、测试时自适应。

## 4. 对三个问题的判断

### 4.1 GPU 配额

1. 论文设计已经把**训练压到 LoRA + 36 万参数头**（单次完整训练 ≈ 23 h 单卡，显存 ≤ 3 GB），昂贵部分是推理与基线。这本身可以写成卖点："在单张消费级 GPU 上一天内训练"——ANNEVO/Carbon-A 做不到。
2. 优先级按"改变结论的概率 / GPU 时"排：P1–P3 决定故事，必须做；P6 基线中 Carbon-A 最贵，可先只跑核心 10 物种（5.1 Gb），两个大基因组放补充。
3. Carbon-A 结果**不需要重复**：CADB 已公开其对 48,167 个装配的注释；若面板物种在 CADB 中，可直接下载其 GFF3（需核对版本与装配一致），省下 72–96 h。**[待核实：CADB 覆盖面板物种与否]**
4. 面板推理用 NT-v2/PC2 路径（160–200 kbp/s）比 GENERanno 路径（17 kbp/s）快约 10 倍；放弃 GENERanno 骨干作最终模型也是省算力的理由之一。

### 4.2 "能做的方向都被做了吗"

被占据的（不要做主贡献）：MoE（ANNEVO、PlantGeneAnn）；GLM 微调 + Viterbi/CRF（Carbon-A、GeneCAD、GeneDecoder）；可微 HMM（Tiberius）；基因置信网络（Carbon-A）；大规模注释资源库（CADB、Tiberius 2,948 装配）。

文献核对后仍空着、且本项目已有部分证据的（05 §3.2 + 本次整理）：

| 空白 | 为什么还空着 | 我们的位置 |
|---|---|---|
| **不完整注释训练**（部分观测似然） | 现有工具的逐碱基交叉熵/HMM 监督把未标注位置当背景；没人报告"k% 标签下的性能曲线" | M30 已证明填背景崩溃；M34 的 k 曲线是决定性实验 |
| **校准后验 + FDR 控制** | 没有工作报告 ECE/可靠性曲线/跨物种校准漂移；Carbon-A 用判别式置信分 | M33 已有 ECE 0.031，优于 Carbon-A 置信网络 |
| **受控骨干分解**（同标签、同解码器、不同 GLM） | 每个工具绑定一个骨干 | 已有三骨干同框架结果 |
| **isoform 感知输出与评估** | Carbon-A/ANNEVO 明确只出最长转录本；评估也只对最长 | 集合后验天然给多条合法结构，解码为 CPU 成本 |
| **多装配/泛基因组一致性** | 所有工具按单基因组评估；泛基因组注释一致性无标准 | 只需推理；后验提供不确定性 |
| **注释噪声感知评估**（参考背景负担） | ANNEVO/Helixer 承认参考不完整，但无系统方法 | M26 已有 reference-background 敏感性 |

可以从 LLM 领域借的、而且算力可承受的做法（按性价比）：

1. **测试时自训练 / 自适应**：对新基因组先零样本推理，取高后验基因作精细标签，其余位置边缘化，LoRA 微调几百步。这是 C2（边缘化）+ C3（校准后验）的直接组合，不需要任何标签，成本 ≈ 一次短训练。若有效，是比"零样本精度"更强的卖点，且 Carbon-A 的训练目标做不到（它没有未知通道）。建议在 M34 后作为 P8 的替代或补充。
2. **弱监督蒸馏**：用 Carbon-A 的高置信预测作为**部分标签**（低置信位置边缘化）在大量无注释基因组上训练开放骨干。属于"合成数据/蒸馏"思路，能解决训练物种少的问题，但新颖性中等，且主张会被读成"学 Carbon-A"；作为备选。
3. **共形预测集合**：对每个位点给出覆盖率保证的结构候选集合（与 isoform 输出合流）。写作上有吸引力，实现是 CPU。
4. **注释数据缩放律**："需要多少注释基因/多少物种"的曲线（M34 T2–T10 × k 已覆盖），是审稿人与用户都关心的实用结论。
5. 不建议：从头 MoE、更大骨干、更长上下文训练（算力不可控且已被占据）。

### 4.3 用户提出的三个方向

**泛基因组**：可做，且便宜（只推理）。建议口径不是"泛基因组注释工具"，而是"**不确定性感知的多装配注释一致性**"：同一模型注释水稻 N 个装配，把后验投射到同源位点，区分"后验一致缺失（真 PAV）"、"后验不确定（结构变异/装配问题）"与"注释差异"；用各材料公开 RNA-seq 做计算验证。风险：需要同源位点映射（minimap2/liftoff 级工具即可）；不需要新训练。适合作 Fig. 6(b)。

**改进"最长转录本"默认**：这是本框架相对 Carbon-A/ANNEVO 的真实结构优势（集合后验），成本低。做法：每个位点输出后验 top-k 合法结构；评估改为"命中任一注释 isoform"并报告 isoform 召回；用 RNA-seq 剪接连接验证新 isoform。风险：ab initio 预测 isoform 的上限可能不高，要把主张限定为"后验排序的候选结构召回更多注释 isoform"而不是"预测可变剪接"。适合作 Fig. 6(a) 或 Fig. 5 的一个面板。**两者取一作主应用，另一进补充**；建议先做 (a)（纯 CPU，与 C3 同一套后验），(b) 作第二篇或补充。

**non-coding RNA 注释**：**不建议进入本篇**。理由：(1) 语法完全不同（无 ORF/相位约束，lncRNA 的"结构"主要由表达定义），当前 CDS 语法与 15 角色不能复用；(2) 参考 lncRNA 注释噪声大、物种间不可比，评估标准没有共识，审稿人无法判断"好"；(3) 需要新的监督和新的基线（无 ab initio lncRNA 基线可比）；(4) 算力上是第二个项目。更现实的中间步是 **UTR/完整转录本语法**（Helixer 预测 UTR，Carbon-A/ANNEVO 不预测），可写进展望，或作第二篇的切入点。

## 6. 坦率评估：按现状能否发子刊，以及怎么调（2026-10-21 补）

### 6.1 现状判断

| 情形 | 判断 |
|---|---|
| 按现有结果（NT-v2+LoRA DEV 63.6，新物种零样本 44–50，比 Carbon-A 低 21–27 点）直接写 | **不能**。框架故事再好，主基准表上最佳模型远落后于最强工具，NC 审稿人会判"工具不可用"。 |
| M34 放大后 DEV ≈ 70、新物种 ≈ 60–65，加校准后验与 k 曲线 | NC 有机会但不稳（估 3–4 成）；Nature Methods 基本无望。原因：C2/C3 是"机制与性质"，缺一个别人做不到的**结果**。 |
| 在上述基础上，加"无标签/证据种子自适应后在时间留出物种上追平或超过 Carbon-A" | NC 概率明显上升，NM 可以尝试。这是唯一能把"精度落后"翻成"能力领先"的路径。 |

ANNEVO 拿 NM 靠三件事：566 物种广度、全面领先、793 物种 BUSCO 级生物学验证。广度我们复制不了，只能靠**深度上的新能力**。

### 6.2 应当升为主线的新方向：目标基因组自举适配

机制：零样本推理 → 取高后验基因（或 BUSCO / miniprot 蛋白比对支持的基因）作精细标签 → 其余位置边缘化 → 对目标基因组做几百步 LoRA → 再推理。

- 为什么只有我们能做：Carbon-A/ANNEVO/Tiberius 的训练目标没有"未知"通道，用自己的预测或稀疏证据做标签会把未标注基因当背景，M30 已证明这会让召回崩溃（−16 / −14 点）。
- 为什么可检验：Dryas / Eschscholzia 已有零样本基线和 Carbon-A 对照；判据写成"自适配闭合零样本差距的比例"，以及"证据种子适配后是否 ≥ Carbon-A 过滤版"。
- 成本：每个基因组一次短训练（估 2–4 GPU 时），全部在 ont 可做；不需要新数据。
- 前提：M34 多物种基模要先有像样的零样本起点（≥ 60），否则自举的伪标签质量不够。
- 风险：M29/M30 显示在饱和的 Carbon-A 特征上适配无增益；但那是"无新信息可学"的情形，在开放骨干上 LoRA 曲线仍在上升（M31），情况不同。若在 Dryas 上闭合差距 < 30%，此方向放弃，回到 §6.4。

次级新方向（本篇不做主线，可作第二篇或补充）：
- 多装配**联合**解码：把泛基因组当作一次联合推理（同源位点共享证据、一致性先验），而不是逐装配注释后比对。真正没人做过，工程量大。
- 参考注释纠错：用后验与参考的系统性分歧标记可疑模型，RNA-seq/Iso-Seq 验证；ANNEVO/Carbon-A 做过类似，新颖性中等。
- 弱监督蒸馏：以 Carbon-A 高置信预测为部分标签在大量无注释基因组上训练开放小模型，解决物种少的问题；新颖性中等，易被读成"学 Carbon-A"。

### 6.3 调整后的主张顺序

1. 自举/证据种子适配（新主线，需 M34 后 1–2 周实验）。
2. 不完整注释训练与注释量曲线（M34 k 臂）。
3. 校准后验与选择性注释（已有）。
4. 骨干无关与分解（已有）。
5. 应用：isoform 感知输出（CPU）；泛基因组一致性作补充或第二篇。
