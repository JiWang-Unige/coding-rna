# coding-rna 结果总清单（2026-11-23；投稿前评估用）

本文件只汇总，不新增结论。每条后面给出原始报告位置（`docs/review_20261016/`）。除特别注明外都是**单 seed、单次运行**；"描述"表示事后读法或不设判据的结果，"判据"表示在看结果之前写定的预注册判定。当前论文大纲：`docs/paper_outline_20261117.md`。

## 0. 方法一句话

一个与骨干无关的概率化基因语法层：在任意 DNA 语言模型（NT-v2、PlantCAD2、GENERanno/Carbon-A）的表示上接一个完整基因结构的 CRF（配分函数训练、精确解码），使模型可以用**不完整注释**训练（未知位置边缘化，"部分观测似然"），并输出**校准的基因级后验**。终版模型 T2 = PlantCAD2 + LoRA + 语法层，只用拟南芥和水稻训练。

评测集：
- **DEV**：拟南芥 + 水稻各一条开发染色体（反复使用，非封存）。
- **set B**：两个时间留出物种（Dryas octopetala、Eschscholzia californica），零样本。
- **独立面板**：核心 10 个植物基因组（时间 / 来源 / 版本留出），一次性打分（报告 25、31）。
- 指标：exact CDS chain F1（整条基因编码结构完全正确才算对）。

## 1. 主张与证据

### C1 骨干无关 + 零样本泛化

- **DEV 受控比较（同头、同语法、同抽样）**：
  - NT-v2 冻结 50.92 → +LoRA 63.61；
  - PlantCAD2 冻结 59.88 → +LoRA 72.22；
  - 终版 T2 73.88 [71.80, 75.63]。
  - 对照：Carbon-A 未过滤 75.24 / 过滤 77.41，ANNEVO 75.70，Tiberius 71.81，GENERanno fresh-joint 70.11，Helixer 62.85。
  - T2 − Carbon-A 过滤 = −3.53 [−4.41, −2.76]（配对 1 Mb 块 bootstrap）。
- **set B 零样本**：T2 68.57 / 68.39；Carbon-A 过滤 73.98 / 73.32；NT-v2+LoRA 49.92 / 44.09。
- **独立面板（预注册判据，判定：不成立；报告 31 §6）**：
  - 核心 10 种中位数：T2 55.05 [54.23, 55.78]；Helixer 42.10、Tiberius 59.25、Vipsania 微调 57.41、ANNEVO 63.08、Carbon-A 未过滤 65.73 / 过滤 67.65。
  - T2 − Carbon-A 过滤 = −12.60（判据线：≤ 6 成立，> 10 不成立）。
  - 描述：差距集中在长基因、多外显子物种（Amborella −28、Hakea −22、Akebia −17）；在只有 GenBank 注释的 5 种上 T2 56.6，与 Tiberius 53.3、Vipsania 56.4 相当。
- **多物种放大无增益**（判据，不成立）：T10（十个植物物种）DEV 72.91，T10 − T2 = −0.96 [−1.52, −0.29]；set B −0.14 [−0.53, +0.28]。
- **T2 的 seed 离散度**：DEV 73.88 / 74.09 / 71.65；set B 68.47 / 66.86 / 65.93。

### C2 不完整注释训练：边缘化（U）优于填背景（F）——论文第一主张（2026-11-17 起）

- **M30（Carbon-A 骨干，参考标签只留 25% 基因）**：U − F = +16.50 / +14.15（Dryas / Esch，CI 远离 0），主要是填背景导致召回崩溃。但在冻结 Carbon-A 特征上 U 与未适配闸门持平。
- **P4（PlantCAD2 骨干，十物种中 8 个新物种的基因只留 50% 标注；预注册判据，成立）**：
  - seed 1：k50U 67.86 − k50F 64.62 = **+3.24，8/8 物种为正**（报告 20 §13）。
  - seed 2（预注册于结果之前，报告 20 §16）：k50U_s2 69.03 − k50F_s2 54.06 = +14.97，8/8。
  - 两 seed 平均 **+9.10，逐物种平均 8/8 为正** → 成立（报告 20 §16.2）。
  - 须一并报告：seed 2 的大差几乎全由 k50F_s2 的选定检查点在新物种上严重少报（召回 43.7%）造成；同步数差值在停点间大幅摆动，两个 seed 在 2304 步差值都为负（−3.95 / −2.49）。结论对检查点敏感。
  - 相对全标签 T10（新物种区段 69.62）：两 seed 平均 k50U −1.18、k50F −10.28。
  - DEV（两臂在这两个物种上都是全标签）：填背景仍拖低 U 1.29 / 0.92 点，两个 seed 的 CI 都不含 0。
- **注释量曲线（描述，seed 1）**：新物种区段 T10 69.62、k50U 67.86、k25U 66.34、k50F 64.62。
- **M36 伪标签 / 证据种子设置（撤回条款触发）**：填背景 − 边缘化 = −0.94 [−1.61, −0.28]，差距 < 2 点，按协议撤回伪标签设置下的 C2，C2 限定为"参考标签部分观测"。
- **外部 0% 参照**：Vipsania（无监督）DEV 微调 69.47、预训练 66.07；set B 预训练 61.68（报告 30）。

### C3 校准的基因后验 → 选择性注释

- NT-v2 + LoRA 版（M33）：τ = 1 即校准，ECE 0.031，AUROC 0.82；按后验过滤 DEV +1.68，新物种 +2.47 / +2.31；DEV 定的阈值在新物种上近似最优。
- PlantCAD2 版（T10，set B，描述）：ECE 0.059 / 0.089，AUROC 0.77 / 0.73，过滤 +2.03 / +1.47。
- **缺口**：终版 T2 在 DEV 和独立面板上的可靠性曲线、FDR 控制曲线还没出图（面板后验已全部算好，CPU 即可）；与 Carbon-A 置信网络的同台比较未做。

### C4 机制（描述）

- 错误主要来自多外显子连接的评分竞争，而非语法容量：TRAIN 匹配重放中 7,762 条漏检里 5,067 条可单独表示且能量为正，但被冲突集合压过。
- ≥6 段 F1：NT-v2+LoRA 53.98 → PlantCAD2+LoRA 71.69（T2）；Carbon-A 过滤 76.49。缺口主要由骨干决定，不由训练物种数决定。
- **M41 长短内含子状态（预注册判据，判定：无可检测效果；协议 33 §9）**：DEV 73.26，≥6 段 70.95；对 T2：≥6 段 −0.74 [−1.71, +0.23]，整体 −0.62；set B 65.06（对 T2 −3.41，多报 12%）。语法层面的这一改动没有缩小长基因缺口。
