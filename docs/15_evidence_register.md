# Evidence Register / 智能归档登记表

> 由 `/note-gate` 和 `/note-add` 维护。凡是对研究推进有长期价值的“指标、决策、用户偏好、失败原因、外部文献、软件输出、讨论结论”都应在这里有一行索引，再路由到更具体的 docs/wiki/refs。

## Capture policy
- 每次 run 结束：必须检查是否记录 metrics、失败原因、seed、配置、输出路径。
- 每次重要讨论结束：必须检查是否记录用户已支持/反对的选项、开放问题、下一步选择理由。
- 每次外部资料进入：必须记录来源、验证状态、是否影响 SOTA/目标。
- 每次 evaluator/metric/split 合约改变：必须路由到 `docs/19` 并在此登记。
- 每次 baseline/SOTA 复现或 waive：必须路由到 `docs/20` 并在此登记。
- 每次真实训练前代码审查：必须路由到 `docs/21` 并在此登记。
- 每次框架升级/兼容修复：必须路由到 `docs/22` 并在此登记。
- 不确定是否值得记录时，宁可写一条短索引，避免只留在对话上下文。
